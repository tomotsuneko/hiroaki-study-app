授業1コマ（50分） 活用 共通テスト ○

名簿の五十音順、テストの点数順、商品の安い順――並べ替えは身の回りのいたるところで使われています。同じ結果になる並べ替えでも、手順（アルゴリズム）によって手間は何倍も変わります。この時間は、並べ替えの手順を考えてプログラムで表し、その手間を数えて比べます。

確認1既習：情Ⅰ-039

配列 Data = [7, 3, 9, 4] のとき、Data[1] の値はどれですか。添字は 0 から始まるものとします。

添字は 0 から始まるので、Data[0] = 7、Data[1] = 3、Data[2] = 9、Data[3] = 4 です。7 を選んだ人は、添字を 1 から数えています。この時間のプログラムはすべて添字 0 から数えます。
確認2既習：情Ⅰ-042

二分探索を使うために、データが満たしていなければならない条件はどれですか。

二分探索は、真ん中の値と比べて「探す値はこれより前か後か」を判断し、探す範囲を半分ずつに絞る方法です。この判断ができるのは、データが順に並んでいるときだけです。つまり、速い探索を使うには、先にデータを並べ替えておく必要があります。これがこの時間のテーマです。
確認3既習：情Ⅰ-038

x = 5、y = 8 のあと、x = y、y = x の順に実行しました。x と y の値はどうなりますか。

代入は「右辺の値を左辺の変数に入れる」命令で、左辺の変数にあった値は消えます（上書き）。x = y で x は 8 になり、もとの 5 は消えます。続く y = x で y にも 8 が入ります。2つの値を入れ替えるには工夫が必要です（本編4で扱います）。

3整列の2つの考え方：選択法と交換法

データを決められた順序に並べ替えることを整列（並べ替え）といいます。小さい順に並べることを昇順、大きい順に並べることを降順といいます。このページでは、特に断らない限り昇順に並べます。

導入の問いに多くの人が考える手順は、大きく2つの型に分けられます。「いちばん小さいものを選び出して前に置く」型と、「隣どうしを比べて逆なら入れ替える」型です。それぞれ選択法、交換法と呼ばれます。

方法A　選択法：最小値を選んで先頭と交換する

  1. まだ並んでいない範囲の中から、最小値を探す（情Ⅰ-039 で学んだ最小値を求める手順と同じ）。
  2. 見つけた最小値を、範囲の先頭の値と交換する。これで先頭の値が確定する。
  3. 範囲を1つ後ろに縮めて、1〜2をくり返す。範囲に残りが1個になったら終わり。
回探す範囲見つけた最小値交換回の終わりの配列（太字は確定）
1回目（i = 0）Data[0]〜Data[4]1（Data[3]）Data[0] と Data[3][1, 3, 8, 5, 4]
2回目（i = 1）Data[1]〜Data[4]3（Data[1]）同じ位置どうし（値は変わらない）[1, 3, 8, 5, 4]
3回目（i = 2）Data[2]〜Data[4]4（Data[4]）Data[2] と Data[4][1, 3, 4, 5, 8]
4回目（i = 3）Data[3]〜Data[4]5（Data[3]）同じ位置どうし（値は変わらない）[1, 3, 4, 5, 8]

方法B　交換法：隣どうしを比べて、逆なら交換する

  1. 隣り合う2つの値を左から順に比べ、左の値のほうが大きければ交換する。
  2. 右端まで進むと、範囲の中の最大値が右端に移って確定する。
  3. 範囲を右端から1つ縮めて、1〜2をくり返す。

くり返すたびに、大きい値が泡（バブル）のように右端へ浮かび上がっていくように見えます。教科書によっては、この「隣り合う2つを比べて入れ替えることをくり返す」整列をバブルソートという名前で扱っています（名前の使い方は教科書によって違うので、自分の教科書で確かめましょう）。

2つの方法に共通すること

どちらも、1回ごとに1つの値の位置が確定し、調べる範囲が1つずつ縮みます。データが n 個なら、n−1 回で全体が並びます（最後に残った1個は自動的に確定します）。違うのは、選択法は先頭から、交換法は末尾から確定していく点です。

よくある間違い

・交換法の1回目で確定するのは、右端の最大値です。左端の最小値ではありません。上の表でも、1回目の後の左端は 3 で、最小値 1 はまだ途中にあります。

・選択法では、最小値を最後まで探し終えてから1回だけ交換します。より小さい値を見つけるたびに交換するのではありません。

例題1

交換法で [7, 2, 6, 4] を昇順に並べます。各回の終わりの配列と、比較の回数・交換の回数を求めましょう。

1回目（i = 0）：7と2 → 交換して [2, 7, 6, 4]、7と6 → 交換して [2, 6, 7, 4]、7と4 → 交換して [2, 6, 4, 7]。右端の 7 が確定します。
2回目（i = 1）：2と6 → そのまま、6と4 → 交換して [2, 4, 6, 7]。6 が確定します。
3回目（i = 2）：2と4 → そのまま。[2, 4, 6, 7] で完了です（4個なので 4−1＝3 回）。
比較は 3＋2＋1＝6 回、交換は 3＋1＝4 回です。比較の回数は1回ごとに1つずつ減ります。

5効率を比べる：手間を回数で数える

同じ結果になるアルゴリズムどうしは、手間で比べます。実行にかかる時間はコンピュータの性能によって変わりますが、「比較を何回したか」「交換を何回したか」は、アルゴリズムとデータだけで決まります。そこで、比較の回数と交換の回数で手間を見積もります。このように、処理にどれだけの手間がかかるかを表す量を計算量といいます。

例のデータで数えてみる

導入の 5, 3, 8, 1, 4 を並べたときの回数です。Cさんの方法は、ある生徒が考えた手順で、「隣どうしを左から比べ、逆の組を見つけたら交換して、また左端から比べ直す。最後まで逆の組がなければ終わり」というものです。この方法でも正しく並びます。

方法比較の回数交換の回数
選択法104（うち2回は同じ位置どうし）
交換法106
Cさんの方法186

Cさんの方法は、交換の回数は交換法と同じですが、交換するたびに左端に戻って、すでに確かめた組をもう一度比べるため、比較が多くなります。逆順の5個では交換法の10回に対して24回、逆順の10個では45回に対して174回になります。結果が正しいことと、効率がよいことは別なのです。

自分の手順と比べよう

導入で考えたあなたの手順では、5, 3, 8, 1, 4 を並べるのに比較が何回必要でしたか。選択法・交換法・Cさんの方法と比べて、多いか少ないか、なぜそうなるかを考えましょう。本編4の部品に同じデータを入れて比べることもできます。

比較の回数は、どちらの方法もデータの並び方に関係なく10回です。交換の回数は、選択法ではいつも n−1 回（4回）ですが、交換法ではデータの並び方によって 0 回から10回まで変わります。交換法の交換の回数は、「大小が逆の順に並んでいる2つの値の組」の数に等しくなります。

比較の回数を式で表す

n 個のデータでは、1回目に n−1 回、2回目に n−2 回、…、最後に1回比べます。比較の回数の合計は (n−1)＋(n−2)＋…＋2＋1 です。n = 5 なら 4＋3＋2＋1＝10 です。この和は、下の図のように点を並べると求められます。

●と○を合わせると、縦 n−1 行・横 n 列の長方形になり、点は全部で (n−1)×n 個です。●はその半分なので、比較の回数は次の式で表せます。

$$ \text{比較の回数} = \frac{n(n-1)}{2} $$

この和の求め方は、数学Bの数列（1 から n までの自然数の和）で詳しく学びます。数学Aの組合せで学ぶ「n 個から2個を選ぶ組の数」も同じ式になります。

データが増えると、手間はどう増える？

基本の選択法・交換法の比較の回数を、データの個数ごとに計算しました。仮に比較1回に 0.000001 秒（100万分の1秒）かかるとして、比較だけにかかる時間も見積もっています。

データの個数 n比較の回数 n(n−1)/2比較1回を 0.000001 秒と仮定したときの時間
10450.000045 秒
1004,950約 0.005 秒
1,000499,500約 0.5 秒
10,00049,995,000約 50 秒
1,000,000499,999,500,000約 50 万秒（約 5.8 日）

データが10倍になると、比較の回数は約100倍

n(n−1)/2 はおよそ n×n÷2 なので、データの個数が10倍になると比較の回数は約100倍、100倍になると約1万倍になります。線形探索（情Ⅰ-042）の比較の回数は多くても n 回なので、100万個でも最大100万回（上の仮定で約1秒）です。整列はそれよりはるかに手間がかかる処理だとわかります。

よくある間違い

「データが10倍なら手間も10倍」と考えがちですが、基本の選択法・交換法では約100倍です。少ないデータで試して速かったからといって、多いデータでも速いとは限りません。アルゴリズムは、データが増えたときの回数の増え方で評価します。

6性能を改善する工夫

本編5の見積もりでは、100万個のデータを基本の方法で並べると、比較だけで約5.8日かかります。データが増えるほど手間は急に増えるので、性能を改善する工夫が必要になります。ここでは、この時間の方法に加えられる工夫の例を見ます。

工夫1　確定した部分は比べない

交換法で j の終わりの値を n - 2 - i にしているのは、この工夫です。毎回 n - 2 まで比べると、比較の回数は (n−1)×(n−1) 回になります。n = 5 では 16 回（工夫ありは 10 回）、n = 1,000 では 998,001 回（工夫ありは 499,500 回）で、約2倍の差になります。

工夫2　交換が1回もなければ打ち切る（交換法）

ある回で交換が1回も起きなかったなら、隣どうしがすべて正しい順に並んでいる、つまり全体が並び終わっています。そこで、交換が起きたかどうかを変数 koukan に記録し、起きなかったら繰返しを終えます。

Data = [1, 3, 5, 4, 8]n = 要素数(Data)i = 0 , koukan = 1i <= n - 2 and koukan == 1 の間繰り返す:｜ koukan = 0｜ j を 0 から n - 2 - i まで 1 ずつ増やしながら繰り返す:｜ ｜ もし Data[j] > Data[j + 1] ならば:｜ ｜ ｜ tmp = Data[j]｜ ｜ ｜ Data[j] = Data[j + 1]｜ ｜ ｜ Data[j + 1] = tmp｜ ⎿ ⎿ koukan = 1⎿ i = i + 1表示する(Data)
データ（5個）基本の交換法の比較の回数打ち切る工夫をした場合
整列済み 1, 3, 4, 5, 8104
ほぼ整列済み 1, 3, 5, 4, 8107
逆順 8, 5, 4, 3, 11010

整列済みの 1,000 個なら、比較は 499,500 回から 999 回に減ります。ただし、逆順のデータでは1回も打ち切れないので、回数は変わりません。

工夫3　不要な交換をしない（選択法）

選択法では、最小値がすでに範囲の先頭にある（saisho と i が等しい）とき、交換しても値は変わりません。そこで、交換の前に もし saisho != i ならば: という条件を置きます。例のデータでは交換の回数が 4 回から 2 回に、整列済みのデータでは 0 回に減ります。本編4の部品で「選択法（不要な交換をしない）」を選ぶと確かめられます。

工夫の効果はデータによって違う

工夫2は、ほぼ並んでいるデータでは大きな効果がありますが、逆順のデータでは効果がありません。アルゴリズムを選ぶときは、扱うデータの特徴も考える必要があります。なお、比較の回数がずっと少なくて済む整列の方法も考え出されていますが、この時間では扱いません。

8まとめ

この時間のまとめ

  • 選択法は「最小値を選んで範囲の先頭と交換」、交換法は「隣どうしを比べて逆なら交換」。どちらも1回ごとに1つの位置が確定し、n 個なら n−1 回で並ぶ。（O1）
  • プログラムでは、配列の添字（0 から）、入れ子の繰返し、条件分岐、tmp を使った値の交換を組み合わせる。j の範囲は、配列の外を参照しないことと、確定した部分を比べないことから決まる。（O2）
  • 効率は比較の回数と交換の回数で比べる。基本の選択法・交換法の比較の回数はどちらも n(n−1)/2 回で、データが10倍になると約100倍に増える。交換の回数は、選択法は n−1 回、交換法はデータの並び方によって 0〜n(n−1)/2 回。（O3）
  • データが多いと手間が急に増えるので、確定した部分を比べない、交換がなければ打ち切る、不要な交換をしない、などの性能を改善する工夫が必要になる。工夫の効果はデータによって違う。（O4）

9確認問題

基本 → 標準 → 入試レベルの順。各問に対応するねらい（O番号）を示す。プログラムはすべて共通テスト用プログラム表記で、添字は 0 から始まる。

基本問1O1

[4, 1, 3, 2] を交換法で昇順に並べます。1回目（i = 0）が終わったときの配列はどれですか。

4と1 → 交換して [1, 4, 3, 2]、4と3 → 交換して [1, 3, 4, 2]、4と2 → 交換して [1, 3, 2, 4]。1回目では右端に最大値 4 が確定します。[1, 4, 3, 2] は最初の比較だけ、[1, 3, 4, 2] は最後の比較を忘れた場合です。[1, 2, 3, 4] は全体が並び終わった状態で、1回目だけではそこまで進みません。
基本問2O1

[6, 2, 9, 1, 5] を選択法で昇順に並べます。1回目（i = 0）が終わったときの配列はどれですか。

範囲全体の最小値 1（Data[3]）を探し、先頭の Data[0] の 6 と交換します。6 は 1 があった位置に移るので [1, 2, 9, 6, 5] です。[1, 6, 2, 9, 5] は値を1つずつ後ろにずらした場合で、選択法では交換する2つ以外は動きません。[2, 6, 9, 1, 5] は最初の2つだけを比べて交換した場合（交換法の考え方）です。[1, 2, 5, 6, 9] は全体が並び終わった状態で、1回目だけではそこまで進みません。
基本問3O2

変数 a と b の値を入れ替える手順として正しいものはどれですか。命令は左から順に実行します。

a = 5、b = 8 として追跡すると、正解の手順は tmp = 5 → a = 8 → b = 5 で入れ替わります。1つ目は a も b も 8 になります（最初の代入で a の値が消える）。3つ目は tmp = 5 → b = 5 → a = 5、4つ目は tmp = 8 → b = 5 → a = 5 となり、どちらも両方 5 になります。「消える前の値を tmp にしまい、最後に tmp から戻す」順序が大切です。
標準問4O2

次のプログラムを実行したとき、(6) 行目 tmp = Data[j] は何回実行されますか。

Data = [3, 5, 2, 4, 1]n = 要素数(Data)i を 0 から n - 2 まで 1 ずつ増やしながら繰り返す:｜ j を 0 から n - 2 - i まで 1 ずつ増やしながら繰り返す:｜ ｜ もし Data[j] > Data[j + 1] ならば:｜ ｜ ｜ tmp = Data[j]｜ ｜ ｜ Data[j] = Data[j + 1]⎿ ⎿ ⎿ Data[j + 1] = tmp表示する(Data)
(6) 行目は交換するときだけ実行されるので、交換の回数を数えます。i = 0：3と5 そのまま、5と2 交換 [3, 2, 5, 4, 1]、5と4 交換 [3, 2, 4, 5, 1]、5と1 交換 [3, 2, 4, 1, 5]（3回）。i = 1：3と2 交換 [2, 3, 4, 1, 5]、3と4 そのまま、4と1 交換 [2, 3, 1, 4, 5]（2回）。i = 2：2と3 そのまま、3と1 交換 [2, 1, 3, 4, 5]（1回）。i = 3：2と1 交換 [1, 2, 3, 4, 5]（1回）。合計 7 回です。比較の回数（10回）と取り違えないようにしましょう。別の確かめ方として、大小が逆の順に並んでいる組（3と2、3と1、5と2、5と4、5と1、2と1、4と1）を数えても7組です。
標準問5O3

50 個のデータを基本の選択法で昇順に並べます。比較は全部で何回行われますか。

比較の回数は 49＋48＋…＋1＝50×49÷2＝1225 回です。データの並び方に関係なく、この回数になります。50×50＝2500 や 50×49＝2450 と答えた人は、「半分にする」ことを忘れています（本編5の図5）。
標準問6O3

基本の交換法で並べるデータの個数が 100 個から 1,000 個に増えました。比較の回数はおよそ何倍になりますか。

比較の回数は 100 個で 4,950 回、1,000 個で 499,500 回なので、約 100 倍（正確には約 100.9 倍）です。n(n−1)/2 はおよそ n×n÷2 なので、n が10倍になると回数は約 10×10＝100 倍になります。「約10倍」は、線形探索のように回数が n に比例する場合の考え方です。
標準問7O4

本編6の「交換が1回もなければ打ち切る」交換法で次の4つのデータを並べるとき、比較の回数がもっとも少なくなるのはどれですか。

[1, 3, 5, 4, 8] は1回目（4回比較）で 5 と 4 が入れ替わって並び終わり、2回目（3回比較）で交換がないので打ち切られます。合計7回です。[3, 1, 8, 5, 4] は9回、[5, 3, 8, 1, 4] と [8, 5, 4, 3, 1] は打ち切れずに10回です。この工夫は、ほぼ並んでいるデータほど効果が大きくなります。

Aさん「選択法のプログラムを、大きい順になるように直せばいいよね。最大値の位置を覚える変数は saidai にしよう。」

Bさん「最大値がもう先頭にあるときは、交換しないようにもしておこう。」

入試問8O1・O2

上のプログラムが貸出回数を多い順（降順）に並べるように、【ア】に入る条件として正しいものはどれですか。

降順では、範囲の中の最大値を選んで先頭と交換します。そのため「それまでの最大値 Kaisu[saidai] より大きい値を見つけたら saidai を更新する」条件にします。Kaisu[j] < Kaisu[saidai] と Kaisu[saidai] > Kaisu[j] は同じ意味で、最小値を選ぶので昇順になります。Kaisu[j] > Kaisu[i] は、それまでの最大値ではなく範囲の先頭と比べているので、1回目に「12 より大きい最後の値」18（Kaisu[4]）が選ばれてしまい、最大値 31 が先頭に来ません。
入試問9O2・O3

【ア】を正しく埋めたプログラムを実行したとき、(9)〜(11) 行目の交換は何回実行されますか。

各回の saidai を追跡します。i = 0：範囲 [12, 25, 7, 31, 18] の最大値 31 の位置 saidai = 3。3 ≠ 0 なので交換し [31, 25, 7, 12, 18]。i = 1：範囲 [25, 7, 12, 18] の最大値は 25 で saidai = 1 = i なので交換しない。i = 2：範囲 [7, 12, 18] の最大値 18 の位置 saidai = 4。交換して [31, 25, 18, 12, 7]。i = 3：範囲 [12, 7] の最大値は 12 で saidai = 3 = i なので交換しない。交換は 2 回です。(8) 行目の条件がなければ4回交換します（そのうち2回は同じ位置どうしで、値は変わりません）。比較の回数は、条件の有無に関係なく 4＋3＋2＋1＝10 回です。
入試問10O3・O4

ある学校で、生徒の記録を基本の交換法で並べるプログラムを使っています。記録が 1,000 件から 10,000 件に増えることになりました。比較の回数がどう変わるかを具体的な回数を示して説明し、性能を改善する工夫が必要になる理由と、工夫の例を1つ述べなさい（100〜150字程度）。

解答例　比較の回数は n(n−1)/2 回なので、1,000 件では 499,500 回、10,000 件では 49,995,000 回になり、件数は10倍でも比較は約100倍に増える。データが増えるほど処理時間が急に長くなるため、確定した部分を比べない、交換が1回もなければ打ち切るなど、手間を減らす工夫が必要である。

採点の観点　①2つの比較の回数を正しく求めている。②件数10倍に対して回数が約100倍（件数の2乗に比例するように増える）ことを指摘している。③工夫が必要な理由（処理時間が急に長くなる）と、工夫の具体例を1つ挙げている。

「件数が10倍だから比較も10倍」と書くと②を満たしません。工夫の例は、本編6の3つ（確定した部分を比べない、交換がなければ打ち切る、不要な交換をしない）のどれかを、手間が減る理由とともに挙げていれば十分です。工夫の効果はデータによって違う（たとえば打ち切る工夫は逆順のデータには効かない）ことにも触れられると、さらによい解答になります。
