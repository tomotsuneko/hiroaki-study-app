前の時間の食酢の中和滴定では、指示薬にフェノールフタレインを使いました。メチルオレンジではいけないのでしょうか。滴定の途中で pH がどう変わるかをグラフにすると、その理由がはっきり見えてきます。

1前回までの確認

この時間は、酸・塩基の強弱と電離度（化基-045）、水素イオン濃度と pH・指示薬の変色域（化基-046）、中和の量的関係（化基-048・049）、滴定の器具と操作（化基-050・051）を使います。中学校では、塩酸に水酸化ナトリウム水溶液を少しずつ加えたときのイオンの数の変化をグラフに表しました（中3-015）。今日はイオンの数の代わりに pH を縦軸にとります。

[H⁺]・[OH⁻] と pH の対応（25℃）

\( [\ce{H+}] \) が 10 倍になると pH は 1 小さくなり、1/10 になると 1 大きくなります。25℃の水溶液では \( [\ce{H+}] \times [\ce{OH-}] = 1.0\times10^{-14}\ (\mathrm{mol/L})^2 \) が成り立つので、塩基性の水溶液の pH は \( [\ce{OH-}] \) からも分かります（化基-046 で触れた水の電離との関係。くわしくは「化学」で学びます）。

確認1既習：化基-046

\( [\ce{H+}] = 1.0\times10^{-3}\ \mathrm{mol/L} \) の塩酸を水で薄めて、\( [\ce{H+}] \) を 1/100 にしました。pH はいくつになりますか。

[H⁺] が 1/10 になるごとに pH は 1 大きくなるので、1/100 では 2 大きくなり、3 → 5 です。「1」は向きを逆にした誤り、「3.01」は pH を [H⁺] の値に比例する量と考えた誤りです。酸を薄めても pH が 7 を超えて塩基性になることはないので「9」も誤りです。
確認2既習：化基-048

0.10 mol/L の塩酸 10.0 mL をちょうど中和するのに必要な 0.10 mol/L の水酸化ナトリウム水溶液の体積は何 mL ですか。

塩酸（1価）が出す H⁺ は \(1 \times 0.10 \times \frac{10.0}{1000} = 1.0\times10^{-3}\) mol。水酸化ナトリウム（1価）が同じ物質量の H⁺ を受け取ればよいので、\(1 \times 0.10 \times \frac{V}{1000} = 1.0\times10^{-3}\) から V = 10.0 mL です。中和に必要な量は物質量で決まり、pH（電離の程度）では決まりません。20.0 mL・5.0 mL は、酸か塩基を2価と考えて価数をかけ間違えた値です。
確認3既習：中3-009・化基-046

フェノールフタレイン溶液を加えた水溶液が赤くなるのは、どのようなときですか。

フェノールフタレインの色が変わる pH の範囲（変色域）は 8.0〜9.8 です。pH 7〜8 の弱い塩基性では無色のままです。「中性から少しでも塩基性になれば赤くなる」わけではないことが、この時間の大事な手がかりになります。

滴定の途中の溶液で、残ったイオンの濃度を求めるには

滴定の途中の溶液の体積は、はじめの溶液の体積と加えた溶液の体積の和とみなします（混ぜたときの体積の変化はわずかなので無視します）。

中和されずに残った H⁺ の濃度は、次のように求めます。
\( [\ce{H+}] \)〔mol/L〕＝ 残った H⁺ の物質量〔mol〕÷ 溶液全体の体積〔L〕
例：塩酸 10.0 mL に水酸化ナトリウム水溶液 9.8 mL を加えたとき、全体の体積は 19.8 mL ＝ 0.0198 L です。塩基が余ったときは、余った OH⁻ について同じように考えます。

3中和点の前後で pH はなぜ急に変わるのか（O1）

中和滴定で、加えた酸または塩基の体積を横軸に、溶液の pH を縦軸にとったグラフを滴定曲線といいます。酸と塩基が過不足なく中和した点を中和点といい、中和点までに加える体積は、中和の量的関係（酸の価数×物質量＝塩基の価数×物質量）で決まります。

図1は、0.10 mol/L の塩酸 10.0 mL に 0.10 mol/L の水酸化ナトリウム水溶液を加えたときの滴定曲線です（\( \ce{HCl + NaOH -> NaCl + H2O} \)）。中和点は 10.0 mL です。

曲線は、はじめはほとんど平らで、中和点の前後でほぼ垂直に立ち上がり、その後はまた平らになります。なぜでしょうか。残っている H⁺ の物質量と pH を並べてみます。

9.90H⁺ が 1.0×10⁻⁵ mol 残る3.3

残っている H⁺ が 1.0×10⁻⁴ mol → 1.0×10⁻⁵ mol → 1.0×10⁻⁶ mol と 1/10 になるたびに、pH は約 1 ずつ上がります。ところが、そのために加える量は 0.9 mL → 0.09 mL と、どんどん少なくて済みます。中和点の直前には H⁺ がほとんど残っていないので、ほんのわずかな塩基で [H⁺] の桁が変わるのです。中和点を過ぎると今度は OH⁻ が余りはじめ、同じように少量で [OH⁻] の桁が変わります。

急変のしくみ

pH は [H⁺] の「桁」を表す目盛りです。中和点の近くでは、残っている H⁺（または余っている OH⁻）の量がとても少ないので、わずかな体積の差で量が何桁も変わり、pH が急に大きく変わります。

滴定曲線で、中和点の前後の pH が急に大きく変わる（曲線がほぼ垂直に立ち上がる）部分を、このページでは急変部と呼びます。図1では、中和点の前後 0.2 mL（9.8〜10.2 mL）の間に pH が 3.0 から 11.0 まで変わります。このページでは、この前後 0.2 mL での pH の範囲を、急変部の範囲の目安として比べます。

例題1　中和点の前後の pH

0.10 mol/L の塩酸 10.0 mL に、0.10 mol/L の水酸化ナトリウム水溶液を (a) 9.8 mL、(b) 10.2 mL 加えたときの pH をそれぞれ求めなさい。混合後の体積は混合前の体積の和とします。

ステップ1：物質量を比べる　塩酸の H⁺ は \(0.10 \times \frac{10.0}{1000} = 1.0\times10^{-3}\) mol。(a) で加えた OH⁻ は \(0.10 \times \frac{9.8}{1000} = 9.8\times10^{-4}\) mol なので、H⁺ が \(2.0\times10^{-5}\) mol 残ります。
ステップ2：濃度にする　全体は 19.8 mL ＝ 0.0198 L。\( [\ce{H+}] = \frac{ 2.0\times10^{-5} }{ 0.0198 } \fallingdotseq 1.0\times10^{-3} \) mol/L なので、(a) は pH 3.0 です。
ステップ3：塩基が余る側　(b) では OH⁻ が \(2.0\times10^{-5}\) mol 余り、全体は 20.2 mL。\( [\ce{OH-}] \fallingdotseq 1.0\times10^{-3} \) mol/L なので、対応表から \( [\ce{H+}] = 1.0\times10^{-11} \) mol/L、(b) は pH 11.0 です。
ステップ4：意味を読む　中和点をはさむ 0.4 mL で pH が 8 も変わります。このため、急変部のどこかで色が変わる指示薬を使えば、中和点を 0.2 mL 以内のずれで見つけられます。

よくある間違い

「中和点＝pH が 7 になる点」ではありません。中和点は物質量の関係で決まる点です。強酸と強塩基の組合せでは、中和点がたまたま pH 7 になりますが、組合せによっては中和点の pH は 7 からずれます（次の節で確かめます）。

4酸・塩基の強弱の組合せで、滴定曲線はどう変わるか（O2）

次の3つの組合せで、いずれもビーカーに 0.10 mol/L の酸 10.0 mL をとり、ビュレットから 0.10 mol/L の塩基を加えます。

  • A 強酸＋強塩基：\( \ce{HCl + NaOH -> NaCl + H2O} \)
  • B 弱酸＋強塩基：\( \ce{CH3COOH + NaOH -> CH3COONa + H2O} \)
  • C 強酸＋弱塩基：\( \ce{HCl + NH3 -> NH4Cl} \)
組合せはじめの pH中和点の pH中和点の前後 0.2 mL での pH の変化中和点までに加えた体積
A 強酸＋強塩基1.07.0（中性）3.0 → 11.010.0 mL
B 弱酸＋強塩基約 2.8約 8.6（塩基性）約 6.3 → 11.010.0 mL
C 強酸＋弱塩基1.0約 5.3（酸性）3.0 → 約 7.710.0 mL

曲線から読み取れること

  1. はじめの pH：同じ 0.10 mol/L でも、弱酸の酢酸は電離度が小さい（約 0.016）ので [H⁺] は約 1.6×10⁻³ mol/L と小さく、pH は約 2.8 です。強酸の塩酸は pH 1.0 です。
  2. 中和点の体積：A・B・C のどれも 10.0 mL です。中和点までに加える量は物質量で決まり、強弱には関係しません。
  3. 中和点の pH：B では塩基性側（約 8.6）、C では酸性側（約 5.3）にずれます。なぜ中性にならないのかは、生じる塩（酢酸ナトリウム、塩化アンモニウム）の水溶液の性質から、次の時間（化基-053）に考えます。
  4. 急変部の範囲：弱い方の側で急変部が短くなります。B では酸性側が、C では塩基性側が縮みます。B は中和点の前に pH がゆるやかに上がり続け、C は中和点の後に pH が約 9.4（20 mL のとき）までしか上がりません。

よくある間違い

「弱酸は電離しにくいので、中和に必要な塩基は少なくて済む」は誤りです。塩基を加えると、まだ電離していない酢酸も次々に反応するので、中和に必要な塩基の物質量は、同じ濃度・同じ体積の強酸と同じです（化基-048）。

実験　pH メーターで滴定曲線をかく

目的　塩酸（強酸）と酢酸水溶液（弱酸）に水酸化ナトリウム水溶液（強塩基）を少しずつ加えて pH を測り、滴定曲線をかいて比べる。

準備　0.10 mol/L 塩酸、0.10 mol/L 酢酸水溶液、0.10 mol/L 水酸化ナトリウム水溶液、ホールピペット（10 mL）、ビュレット、ビーカー、pH メーター、かくはん器（またはガラス棒）、フェノールフタレイン溶液、メチルオレンジ溶液、保護眼鏡

操作

  1. pH メーターを、pH の値が分かっている標準液で校正する。
  2. ホールピペットで塩酸 10.0 mL をビーカーにとる。電極が液に浸らないときは純水を加えてよい（酸の物質量は変わらないので、中和点の体積は変わらない）。
  3. ビュレットから水酸化ナトリウム水溶液を 1.0 mL ずつ加え、よくかき混ぜてから pH を記録する。中和点の近く（8〜12 mL）では 0.1〜0.2 mL ずつ加える。
  4. 酢酸水溶液でも同じように測定し、2本の滴定曲線を同じグラフにかく。
  5. 別のビーカーで、それぞれの指示薬を1〜2滴加えて同じ滴定を行い、色が変わったときの体積を記録する。

結果の読み取り　(1) 急変の中央はどちらも 10.0 mL で、中和点の体積は同じ。(2) 酢酸では 0〜8 mL で pH が約 2.8 から約 5.2 までゆるやかに上がり、急変は約 6.3 から始まる。(3) 指示薬の色が変わった体積を急変部と比べると、どの指示薬が使えるかが分かる（次の節）。

安全　保護眼鏡を着用する。水酸化ナトリウム水溶液は皮膚や目を強く侵すので、付いたらすぐに多量の水で洗い、先生に知らせる。ビュレットに溶液を入れるときは、目より低い位置でろうとを使って静かに入れ、入れ終わったらろうとを外す。フェノールフタレイン溶液はエタノールを含むので火気に近づけない。廃液は指定の容器に集める。

5指示薬はどう選ぶのか（O3）

指示薬は、pH によって色が変わる物質です。色が変わる pH の範囲を変色域といいます。中和滴定でよく使う指示薬は次の2つです（変色域の値は資料によって少し異なることがあります）。

指示薬変色域（pH）変色域より酸性側の色変色域より塩基性側の色
メチルオレンジ3.1〜4.4赤黄（変色域の中は橙）
フェノールフタレイン8.0〜9.8無色赤（変色域の中はうすい赤）

指示薬を選ぶ基準

変色域が、滴定曲線のほぼ垂直に立ち上がる部分の pH の範囲に入っている指示薬を選びます。そうすれば、わずかな体積の差で色が変わり、色が変わった点が中和点とほぼ一致します。中和点の pH が変色域の中にあるかどうかではなく、急変部と重なるかどうかで判断します。

B 弱酸＋強塩基約 6.3〜11.0使えない（約 4.0 mL で黄色になってしまう）使える（10.0 mL の前後 0.02 mL 以内で色が変わる）

前の時間の食酢（酢酸）の滴定で、フェノールフタレインを使った理由がこれで分かります。酢酸と水酸化ナトリウムの組合せ（B）では、急変部が塩基性側にしかないからです。

操作してみよう：滴定曲線と指示薬の色

組合せを選ぶ

体積：0.00 mL pH：1.0（酸性） フェノールフタレイン：無色 メチルオレンジ：赤

  • B を選び、メチルオレンジが黄色になる体積を探してみよう（中和点の 10.0 mL よりずっと前です）。
  • C を選び、フェノールフタレインの色を見ながら 20 mL まで動かしてみよう。
  • どの組合せでも、pH が急に変わるのは 10.0 mL の前後であることを確かめよう。

例題2　指示薬を間違えるとどうなるか

0.10 mol/L の塩酸 10.0 mL に 0.10 mol/L のアンモニア水を加える滴定で、指示薬にフェノールフタレインを使うと、どのような問題が起こりますか。図2の C を使って説明しなさい。

ステップ1：急変部を確かめる　C の中和点は 10.0 mL、中和点の pH は約 5.3 で、急変部は pH 3.0〜約 7.7 の酸性側にあります。
ステップ2：変色域と重ねる　フェノールフタレインが色づき始める pH 8.0 になるのは、中和点を過ぎてアンモニア水が余ってから（約 10.4 mL）です。その後も pH はゆるやかにしか上がらず、20 mL 加えても約 9.4 で、赤色（pH 9.8 以上）になりません。
ステップ3：結論　色の変化がゆるやかで、中和点より遅れて色づくため、中和点の体積を正しく読めません。読んだ体積が大きすぎれば、塩酸の濃度を実際より大きく見積もってしまいます。この組合せでは、急変部に変色域が入るメチルオレンジ（中和点の 0.01 mL 手前までに黄色になる）を使います。

よくある間違い

「中和点では中性になるから、pH 7 付近で色が変わる指示薬を選ぶ」は誤りです。B・C では中和点の pH は 7 ではありません。また、選ぶ基準は中和点の pH の値そのものではなく、急変部と変色域が重なるかです。

7まとめ

この時間のまとめ

  • 滴定曲線は、加えた体積と pH の関係のグラフ。中和点の近くでは、残る H⁺（余る OH⁻）の量が桁で変わるので、わずかな体積で pH が急に大きく変わる。（O1）
  • 中和点までに加える体積は、酸・塩基の強弱によらず物質量の関係で決まる。（O1・O2）
  • 強弱の組合せで、はじめの pH・中和点の pH・急変部の範囲が変わる。中和点の pH は、強酸＋強塩基で 7、弱酸＋強塩基で塩基性側（約 8.6）、強酸＋弱塩基で酸性側（約 5.3）。（O2）
  • 変色域が急変部に入る指示薬を選ぶ。弱酸＋強塩基はフェノールフタレイン、強酸＋弱塩基はメチルオレンジ、強酸＋強塩基はどちらでもよい。（O3）
中和点の条件（a・b は酸・塩基の価数）$$ a \times c \times V = b \times c' \times V' $$

c・c′ はモル濃度、V・V′ は体積（単位をそろえる）。

pH と [H⁺]（25℃）$$ [\ce{H+}] = 1.0\times10^{-n}\ \mathrm{mol/L} \iff \mathrm{pH} = n $$

\( [\ce{H+}][\ce{OH-}] = 1.0\times10^{-14}\ (\mathrm{mol/L})^2 \)

8確認問題

基本 → 標準 → 入試レベルの順。各問に対応するねらい（O番号）を示す。数値は 25℃ とし、混合後の体積は混合前の体積の和とする。

基本問1O1

「中和点」の説明として正しいものを選びなさい。

中和点は、酸が放出する H⁺ と塩基が受け取る H⁺ の物質量が等しくなる点で、物質量の関係で決まります。pH 7 になるのは強酸と強塩基の組合せだけです。指示薬の色が変わる点は、適切な指示薬を選んだときに中和点とほぼ一致する「目印」で、中和点そのものではありません。pH は塩基を加え続ける限り上がり続けるので、「最も大きくなった点」もありません。
基本問2O3

フェノールフタレインについて正しいものを選びなさい。

フェノールフタレインの変色域は 8.0〜9.8 で、酸性側で無色、塩基性側で赤色です。pH 3.1〜4.4 はメチルオレンジの変色域です。「pH 7 を境に変わる」は誤りで、pH 7〜8 では無色のままです。4つ目は色の向きが逆です。
標準問3O2（グラフの読み取り）

ビーカーに入れた 0.10 mol/L の水溶液 10.0 mL に、ビュレットから 0.10 mol/L の水溶液を加えたところ、下の滴定曲線が得られました。ビーカーとビュレットの溶液の組合せとして最も適当なものを選びなさい。

はじめの pH が約 11 で、加えるにつれて pH が下がるので、ビーカーは塩基、ビュレットは酸です（3つ目・4つ目は誤り）。0.10 mol/L の水酸化ナトリウム水溶液なら [OH⁻] = 1.0×10⁻¹ mol/L で pH 13 から始まるはずですが、約 11 から始まっているので弱塩基です。さらに、中和点（10.0 mL）の pH が約 5.3 と酸性側にあり、急変部が pH 約 7.7 から 3.0 までの酸性寄りの範囲にあることも、強酸＋弱塩基の組合せ（図2の C を逆向きにたどったもの）であることを示しています。
標準問4O2（グラフの読み取り）

濃度の分からない酢酸水溶液 10.0 mL を 0.10 mol/L の水酸化ナトリウム水溶液で滴定したところ、下の滴定曲線が得られました。中和点を読み取り、酢酸水溶液のモル濃度〔mol/L〕を有効数字2桁で答えなさい。

pH がほぼ垂直に立ち上がる部分の中央が中和点で、7.5 mL です（7.3 mL で pH 約 6.1、7.7 mL で約 11.1）。酢酸も水酸化ナトリウムも1価なので、\(1 \times c \times 10.0 = 1 \times 0.10 \times 7.5\) より \(c = 0.075\) mol/L（7.5×10⁻² mol/L）です。中和点の pH（約 8.6）は 7 ではないので、「pH 7 の位置」を探すのではなく、急変部の中央を読みます。
標準問5O1

0.10 mol/L の水酸化ナトリウム水溶液 10.0 mL に、0.10 mol/L の塩酸を 10.2 mL 加えました。この溶液の pH を整数で答えなさい。

OH⁻ は \(0.10 \times \frac{10.0}{1000} = 1.0\times10^{-3}\) mol、加えた H⁺ は \(1.02\times10^{-3}\) mol なので、H⁺ が 2.0×10⁻⁵ mol 余ります。全体は 20.2 mL ＝ 0.0202 L で、\( [\ce{H+}] = \frac{ 2.0\times10^{-5} }{ 0.0202 } \fallingdotseq 1.0\times10^{-3} \) mol/L、pH は 3 です。中和点（10.0 mL、pH 7）からわずか 0.2 mL で pH が 4 も下がることに注目しましょう。中和で消費された分を引かずに、加えた H⁺ の全量（1.02×10⁻³ mol）で計算すると pH 約 1.3 となり、誤りです。
標準問6O3

中和滴定の指示薬の選び方として適当でないものを選びなさい。

強酸＋弱塩基（塩酸とアンモニア水）では、急変部が pH 3.0〜約 7.7 の酸性側にあり、フェノールフタレインの変色域 8.0〜9.8 と重なりません（例題2）。強酸＋強塩基は急変部が 3.0〜11.0 と広いので、どちらの指示薬も使えます。弱酸＋強塩基はフェノールフタレイン、強酸＋弱塩基はメチルオレンジが適当です。
入試問7O2・O3

ある生徒が、0.10 mol/L 相当に薄めた食酢（酸は酢酸だけとする）10.0 mL を 0.10 mol/L の水酸化ナトリウム水溶液で滴定しました。指示薬にメチルオレンジを使い、溶液が黄色になったところで滴下をやめて、その体積から酢酸の濃度を計算しました。図2の B を参考にして、このときの結果として最も適当なものを選びなさい。

B の曲線は、中和点の前に pH が約 2.8 からゆるやかに上がり、約 4.0 mL で pH 4.4（メチルオレンジが黄色になる pH）に達します。この体積で計算すると \(c = 0.10 \times \frac{4.0}{10.0} = 0.040\) mol/L となり、実際の 0.10 mol/L の約 4 割しかありません。メチルオレンジの変色域（3.1〜4.4）が急変部（約 6.3〜11.0）より酸性側にあるためです。「約 10 mL」はフェノールフタレインを使った場合の結果です。「約 16 mL」「20 mL 加えても黄色にならない」は、メチルオレンジが塩基性側で色を変えると取り違えた答えで、実際には酸性側の pH 4.4 で黄色になります。
入試問8O1・O2・O3

酢酸水溶液を水酸化ナトリウム水溶液で滴定するとき、指示薬としてフェノールフタレインは適当で、メチルオレンジは適当でない理由を、滴定曲線の形と変色域にふれて 120 字程度で説明しなさい。

解答例　弱酸と強塩基の滴定では、中和点付近で pH がおよそ 6 から 11 まで急に変化し、この急変部は塩基性側にある。フェノールフタレインの変色域 8.0〜9.8 は急変部に入るが、メチルオレンジの変色域 3.1〜4.4 は急変部より酸性側にあり、中和点よりかなり前に色が変わるから。

採点の観点　(1) 中和点付近で pH が急変すること、その範囲が塩基性側（およそ 6〜11）にあることを書いている。(2) 2つの指示薬の変色域を急変部と比べている。(3) メチルオレンジでは中和点より前に色が変わる（体積を小さく読む）ことを書いている。

「中和点で中性になるから」と書くのは誤りです。酢酸と水酸化ナトリウムの中和点は塩基性側にあります（理由は次の時間、化基-053）。判断の基準は、中和点の pH そのものではなく「急変部と変色域が重なるか」です。
