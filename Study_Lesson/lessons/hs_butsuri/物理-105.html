電磁誘導と誘導起電力の向き

授業1コマ（50分） 学習 共通テスト ○ † 教科書で一般的な内容を含む

磁石をコイルに出し入れすると電流が流れることは、中学校で学びました。では、その電流の向きはどう決まるのでしょうか。「N極を近づけたらこっち向き」と場合ごとに覚えるのではなく、どんな場合にも使える一つの原理――レンツの法則――で判断できるようになりましょう。

0この時間のねらい

この時間でできるようになること

  • O1コイルを貫く磁束（Φ＝BS）の意味を知り、磁束が変化するときにだけ誘導起電力が生じることを説明できる。
  • O2誘導起電力の向きを、誘導電流がつくる磁界がコイルを貫く磁束の変化を妨げる向き（レンツの法則）として、手順に沿って判断できる。
  • O3磁石やコイルの動かし方・電流の変化などいろいろな場合に誘導電流の向きを判断し、誘導電流が磁石の運動を妨げる力を及ぼすことをエネルギーの保存と関連付けて説明できる。

1前回までの確認

この時間は、電流がつくる磁界の向き（右ねじの法則）、磁束密度、中学校で学んだ電磁誘導の実験を使います。小問で確かめましょう（このページでは学習指導要領にならって「磁界」と書きます。教科書によっては「磁場」と書かれています）。

確認1既習：物理-098・物理-100

図のコイルの手前側の導線（実線）で、電流が下向きに流れています。コイルの内部の磁界はどちら向きですか。

右手の4本の指を電流の向きに合わせてコイルを握ると、親指の向きが内部の磁界の向きです（右ねじの法則、物理-098・物理-100）。手前で下向き・奥で上向きの電流は、コイルの右側から見ると反時計回りで、磁界は見ている人に向かう右向きになります。「ある側から見て反時計回りの電流 → その側に向かう磁界」は、この時間くり返し使います。左向きは、手前の導線と奥の導線を取り違えたか、右ねじの向きを逆にとった答えです。上向き・下向きは導線の電流の向きと磁界の向きを混同した答えです。
確認2既習：物理-101

磁束密度 B の単位はどれですか。

磁束密度の単位は T（テスラ）です（F＝IBL から 1 T＝1 N/(A·m)）。A/m は磁界の強さ H の単位です。この時間は、磁束密度と面積から求める「磁束」（物理-101）を使います。下の囲みで確認しましょう。
確認3既習：中2-126

検流計につないだコイルに棒磁石の N 極を入れ、そのまま静止させました。検流計の針はどうなりますか。

磁石やコイルが動いている間だけ電流が流れ、止めると電流は流れません（中2-126）。「磁石がコイルの中にあること」ではなく「動いていること」が必要です。この理由を、この時間は「磁束の変化」として説明します。

磁束 Φ＝BS の確認（物理-101）

物理-101 で学んだように、磁束密度 B〔T〕の一様な磁界に垂直に置いた、面積 S〔m²〕の面を貫く磁束 Φ は \( \Phi = BS \) です。単位はウェーバ（記号 Wb、1 Wb＝1 T·m²）です。磁束は「面を貫く磁力線の束の量」、磁束密度は「磁界に垂直な面 1 m² あたりの磁束」とイメージできます。磁束の向きは、面を貫く磁界の向きです。

例：B＝0.10 T、S＝3.0×10⁻³ m² なら、\( \Phi = 0.10 \times 3.0 \times 10^{-3} = 3.0 \times 10^{-4} \) Wb。

面が磁界に対して傾いているときは、磁界に垂直な面に投影した面積を使います（物理-112「交流の発生」で使います）。

2導入：コイルの電流は磁石を引き寄せる？押し返す？

予想してみよう

検流計につないだコイルに、棒磁石の N 極を近づけると電流が流れます。電流が流れたコイルは電磁石になります。この電磁石は、近づいてくる磁石を①引き寄せるでしょうか、②押し返すでしょうか。

もし①だったとしたら、磁石をほんの少しコイルに押しただけで何が起こるでしょうか。考えてから読み進めましょう。答えは本編の「エネルギーから見たレンツの法則」で分かります。

3磁束の変化と誘導起電力：何が変わると電流が生じるのか

中学校の実験をもう一度

  • 磁石をコイルに入れたり出したりすると、検流計の針が振れる（電流が流れる）。
  • 磁石を止めると、コイルの中にあっても針は 0 に戻る。
  • 動かす向きや磁極を逆にすると、針は逆に振れる。速く動かすほど大きく振れる（中2-126・中2-127）。

変化しているのは「コイルを貫く磁束」

磁石がコイルに近づくと、コイルの位置の磁界が強くなり、コイルを貫く磁力線が増えます（図1）。つまり、コイルを貫く磁束 Φ（物理-101。前回までの確認の囲み）が増えています。遠ざけると磁束は減り、止めると磁束は変わりません。

コイルを貫く磁束 Φ が変化すると、コイルに電圧が生じます。この現象を電磁誘導、生じる電圧を誘導起電力、それによって流れる電流を誘導電流といいます。磁束が変化するのは、例えば次のような場合です。

  1. 磁石をコイルに近づける・遠ざける（コイルの位置の磁束密度が変わる）。
  2. 磁石を止めて、コイルのほうを動かす（磁石とコイルの相対的な動きが同じなら、同じことが起こる）。
  3. 近くに置いた電磁石の電流を変える、スイッチを入れたり切ったりする。
  4. 磁界の中でコイルの面積や向きを変える（コイルを回転させる場合は 物理-112「交流の発生」で学ぶ）。

誘導起電力が生じる条件

誘導起電力が生じるのは、コイルを貫く磁束が「ある」ときではなく、磁束が「変化する」ときです。

誘導起電力は、コイルを電池のように働かせます（起電力：物理-091）。コイルが閉じた回路の一部なら誘導電流が流れます。回路が途中で切れていても、コイルの両端には誘導起電力が生じています（電流が流れないだけです）。なお、磁束の変化が速いほど誘導起電力は大きくなります（中学校で見た「速く動かすほど大きな電流」）。大きさを式で表す電磁誘導の法則は、物理-107 で学びます。

よくある間違い

①「強い磁石をコイルの中に入れておけば、電流が流れ続ける」→ 誤り。磁束が大きくても、変化しなければ誘導起電力は 0 です。

②「回路が切れていると電磁誘導は起こらない」→ 誤り。誘導起電力は生じます。電流が流れないだけです。

例題1　磁束とその変化

断面積 5.0×10⁻³ m² のコイルが、コイルの面に垂直な磁束密度 0.20 T の一様な磁界の中にあります。(1) コイルを貫く磁束を求めなさい。(2) 磁束密度を 0.50 T に増やしたときの、磁束の変化 ΔΦ を求めなさい。(3) 磁束密度を 0.50 T のまま保つとき、誘導起電力は生じるか答えなさい。

ステップ1：\( \Phi = BS = 0.20 \times 5.0 \times 10^{-3} = 1.0 \times 10^{-3} \) Wb。
ステップ2：0.50 T のとき \( \Phi' = 0.50 \times 5.0 \times 10^{-3} = 2.5 \times 10^{-3} \) Wb。\( \Delta\Phi = \Phi' - \Phi = +1.5 \times 10^{-3} \) Wb（増加）。
ステップ3：磁束が変化しないので、誘導起電力は生じない。誘導起電力が生じるのは、磁束密度を増やしている途中だけ。
答え：(1) 1.0×10⁻³ Wb　(2) ＋1.5×10⁻³ Wb　(3) 生じない

4レンツの法則：誘導電流は「変化を妨げる向き」に流れる

レンツの法則

誘導起電力は、それによって流れる誘導電流がつくる磁界が、コイルを貫く磁束の変化を妨げる向きに生じる。

向きを決める3つの手順

  1. 磁束を調べる：コイルを貫く磁束の向きと、それが増えるか減るかを調べる。
  2. 誘導電流の磁界を決める：磁束が増えるなら逆向き、減るなら同じ向き（元に戻そうとする向き）。
  3. 電流の向きを決める：その磁界をつくる電流の向きを、右手（右ねじの法則）で決める。
場合磁石の磁界（コイル内）磁束の変化誘導電流の磁界電流（磁石側から見て）コイルの磁石側の端磁石が受ける力
(a) N極を近づける左向き増加右向き（逆向き）反時計回りN極押し返される
(b) N極を遠ざける左向き減少左向き（同じ向き）時計回りS極引き戻される
(c) S極を近づける右向き増加左向き（逆向き）時計回りS極押し返される
(d) S極を遠ざける右向き減少右向き（同じ向き）反時計回りN極引き戻される

よくある間違い

「誘導電流の磁界は、いつも磁石の磁界と逆向き」は誤りです。逆向きになるのは磁束が増えるときだけで、減るときは同じ向きになります（表の (b)(d)）。「妨げる」のは磁界そのものではなく、磁束の変化です。

例題2　N極を近づけるときの電流の向き

図2(a) のように、コイルの右側から棒磁石の N 極を近づけます。コイルに流れる誘導電流の向きを、磁石側（右側）から見た回り方で答えなさい。

ステップ1（磁束を調べる）：N 極から出る磁界は、コイルの中では左向き。磁石が近づくので、左向きの磁束が増加する。
ステップ2（誘導電流の磁界）：増加を妨げるので、誘導電流はコイルの中に右向き（逆向き）の磁界をつくる。このときコイルの右端（磁石側）は N 極になり、近づく N 極を押し返す。
ステップ3（電流の向き）：右向きの磁界をつくる電流は、右側から見て反時計回り（右手の親指を右に向けて握る向き）。
答え：磁石側から見て反時計回り。

動かして確かめよう：レンツの法則　コイルに向ける極と磁石の動きを選ぶと、3つの手順に沿って誘導電流の向きが表示されます。先に自分で予想してから確かめましょう。

    検流計は、磁石側から見て反時計回りの電流が流れると右に振れるようにつないだものとしています。

    5いろいろな場合の向きと、エネルギーから見たレンツの法則

    動くのがコイルでも、電流を変えても同じ手順

    磁石を止めてコイルのほうを磁石の N 極に近づけても、コイルを貫く左向きの磁束は同じように増えるので、図2(a) と同じ向きの電流が流れます。電磁誘導は、磁石とコイルの相対的な動きで決まります。

    電磁石（コイル1）とコイル2 を同じ軸の上に並べ、コイル1 のスイッチを入れると、コイル2 を貫く磁束が増えるので、コイル2 にはコイル1 と逆向き（同じ側から見て逆の回り方）の電流が流れます。スイッチを切ると磁束が減るので、同じ向きの電流が流れます。一方のコイルの電流の変化で他方のコイルに起電力が生じる現象は、物理-111「相互誘導」で詳しく学びます。

    誘導電流は、磁石の動きを妨げる

    図2の表の最後の列を見ると、磁石を近づけると押し返され、遠ざけると引き戻されています。どの場合も、誘導電流は磁石の動きを妨げる力を及ぼします。

    例題3　落下する磁石が受ける力

    N 極を下にした棒磁石を、水平に置いたコイル（両端はつないで閉じた回路にしてある）の真上から落とします。磁石がコイルに近づくとき、コイルを通り抜けて遠ざかるとき、それぞれ誘導電流は上から見てどちら回りですか。また、磁石はコイルの電流からどちら向きの力を受けますか。

    ステップ1（近づくとき）：コイルの中の磁石の磁界は下向きで、増加する。誘導電流は上向きの磁界をつくるので、上から見て反時計回り。コイルの上面が N 極になり、磁石の下端の N 極を押し返す → 磁石は上向きの力を受ける。
    ステップ2（遠ざかるとき）：コイルは磁石の上端（S 極）の上側にあり、S 極に入り込む磁界はコイルの位置で下向き。磁石が遠ざかるので、この下向きの磁束が減少する。誘導電流は下向きの磁界をつくるので、上から見て時計回り。コイルの下面が N 極になり、磁石の上端の S 極を引き寄せる → 磁石は上向きの力を受ける。
    ステップ3（まとめ）：どちらの場合も、磁石は落下を妨げる上向きの力を受ける。電流の回り方は近づくときと遠ざかるときで逆になるが、力の向きはどちらも「動きを妨げる向き」。
    答え：近づくとき 反時計回り、遠ざかるとき 時計回り。力はどちらも上向き。

    エネルギーから見たレンツの法則

    磁石を近づけるとき押し返されるので、磁石を動かし続けるには、外から仕事をする必要があります。この仕事が誘導電流の電気エネルギーになり、回路の抵抗でジュール熱（物基-061）などに変わります。発電機で電気エネルギーを得るのに、タービンなどを回す仕事が必要なのも同じ理由です（物基-062）。

    もし誘導電流が変化を助ける向きに流れたとしたら、導入の①のように磁石は引き寄せられて加速し、磁束の変化が速くなって電流も増え、さらに強く引き寄せられます。外から仕事をしなくても、運動エネルギーと電気エネルギーが増え続けることになり、エネルギー保存の法則に反します。したがって導入の答えは②「押し返す」です。

    レンツの法則とエネルギー

    誘導電流は、原因（磁束の変化、磁石やコイルの動き）を妨げる向きに流れる。だから、電気エネルギーを得るには外から仕事をしなければならない。レンツの法則は、エネルギーの保存と結び付いた法則です。

    よくある間違い

    「近づくとき押し返されるなら、遠ざかるときも押し出される（加速される）」→ 誤り。遠ざかるときは引き戻されます。力の向きは「磁石の位置」ではなく「動き」を妨げる向きです。なお、コイルの回路を開いておくと電流が流れないので、磁石は力を受けません（誘導起電力は生じています）。

    6実験：誘導電流の向きを予想して確かめる

    実験：レンツの法則で予想した誘導電流の向きを検流計で確かめる

    目的　磁石の極と動かし方を変えたときの誘導電流の向きを、レンツの法則で予想してから検流計で調べ、予想と比べる。

    準備　巻く向きが分かるコイル、検流計、棒磁石、乾電池、大きな抵抗（保護抵抗）、導線

    方法

    1. 検流計の振れの向きと電流の向きの関係を調べる。乾電池と保護抵抗を直列にして検流計につなぎ、どちらの端子から電流が入ると針が右に振れるかを記録する（乾電池を検流計に直接つながない）。
    2. コイルの巻く向きを見て、どちらの端子から電流を流すとコイルの磁石側の端が N 極になるかを、右手で確かめておく。
    3. コイルを検流計につなぐ。N 極を近づける・遠ざける、S 極を近づける・遠ざける、の4通りについて、レンツの法則で針の振れの向きを予想してから、磁石を動かして確かめる。
    4. 磁石をコイルの中で止めたとき、動かす速さを変えたときの針のようすも調べる。
    操作予想：コイルの磁石側の端予想：電流（磁石側から見て）結果：検流計の振れ
    N極を近づけるN極反時計回り（記入）
    N極を遠ざけるS極時計回り（記入）
    S極を近づけるS極時計回り（記入）
    S極を遠ざけるN極反時計回り（記入）

    結果の読み取り　4通りすべてで、針が予想した向きに振れれば、レンツの法則で向きを説明できることが確かめられます。磁石を止めると針は 0 に戻り（磁束が変化しない）、速く動かすほど大きく振れますが、振れる向きは変わりません。向きは「磁束が増えるか減るか」で、大きさは「変化の速さ」で決まることが分かります。

    安全のために　強い磁石（ネオジム磁石など）どうしや鉄製品の間に指をはさまないように注意する。磁石を落としたりぶつけたりしない（割れて破片が飛ぶことがある）。磁気カードや精密機器に磁石を近づけない。検流計に乾電池を直接つながない（大きな電流で検流計が壊れる）。

    次の時間（物理-106）は、検流計のかわりにオシロスコープを使い、誘導起電力の向きだけでなく大きさと時間変化まで調べて、磁束の変化との関係を見いだします。

    7重要語句

    この時間の重要語句

    電磁誘導
    コイルを貫く磁束が変化するときに、コイルに起電力が生じる現象。
    誘導起電力
    電磁誘導によって生じる起電力（電圧）。回路が開いていても生じる。
    誘導電流
    誘導起電力によって、閉じた回路に流れる電流。
    磁束
    磁界に垂直な面を貫く磁力線の束の量。磁束密度 B の一様な磁界に垂直な面積 S の面では Φ＝BS。
    ウェーバ（Wb）
    磁束の単位。1 Wb＝1 T·m²。
    レンツの法則
    誘導起電力は、誘導電流がつくる磁界がコイルを貫く磁束の変化を妨げる向きに生じる、という法則。
    検流計
    小さな電流の向きと大きさを調べる計器。針の振れる向きで電流の向きが分かる。
    磁束密度
    磁界の強さと向きを表す量（単位 T）。磁界に垂直な面 1 m² あたりの磁束。
    右ねじの法則
    電流の向きと、その電流がつくる磁界の向きの関係。コイルでは、右手の4本の指を電流の向きに合わせて握ったときの親指の向きが内部の磁界の向き。

    8まとめ

    この時間のまとめ

    • コイルを貫く磁束は Φ＝BS（単位 Wb）。磁束が変化するときにだけ誘導起電力が生じ、閉じた回路なら誘導電流が流れる（O1）。
    • レンツの法則：誘導電流は、コイルを貫く磁束の変化を妨げる向きの磁界をつくる。手順は ①磁束の向きと増減 ②増えるなら逆向き・減るなら同じ向きの磁界 ③右手で電流の向き（O2）。
    • 磁石・コイルのどちらが動いても、電磁石の電流を変えても、同じ手順で判断できる。誘導電流は磁石の動きを妨げる力を及ぼし、外からの仕事が電気エネルギーになる。これはエネルギーの保存と結び付いている（O3）。
    磁束（面が磁界に垂直なとき）$$ \Phi = BS \quad [\mathrm{Wb}] $$
    レンツの法則の手順

    磁束が増える → 誘導電流の磁界は逆向き
    磁束が減る → 誘導電流の磁界は同じ向き
    変化しない → 誘導電流は流れない

    9確認問題

    基本 → 標準 → 入試レベルの順。各問に対応するねらい（O番号）を示す。

    基本問1O1

    検流計につないだコイルに誘導電流が流れるのはどれですか。

    引き抜くとコイルを貫く磁束が減るので、誘導起電力が生じて電流が流れます。静止させた場合や横に置いたままの場合は、磁束があっても変化しません。一緒に動かす場合も、磁石とコイルの位置関係が変わらないので磁束は変化しません。
    基本問2O1

    面積 4.0×10⁻³ m² の面が、磁束密度 0.30 T の一様な磁界に垂直に置かれています。この面を貫く磁束は □×10⁻³ Wb です。□に入る数値を答えなさい。

    \( \Phi = BS = 0.30 \times 4.0 \times 10^{-3} = 1.2 \times 10^{-3} \) Wb なので、□は 1.2。単位 Wb＝T·m² から、T と m² を掛けると Wb になることも確かめましょう。
    基本問3O2

    コイルに棒磁石の N 極を近づけました。誘導電流によって、コイルの磁石側の端は何極になりますか。

    近づくことによる磁束の増加を妨げるため、コイルは近づく N 極を押し返す向きの電磁石になります。押し返すのは同じ極どうしなので、磁石側の端は N 極です。S 極と答えた人は、「磁石を引き寄せる」と考えています（それではエネルギー保存の法則に反します）。「どちらにもならない」は、近づけている間は磁束が変化して誘導電流が流れることを見落とした答えです。
    標準問4O2

    コイルから棒磁石の N 極を遠ざけるとき、誘導電流がコイルの中につくる磁界の向きは、磁石がコイルの中につくる磁界の向きと比べてどうなりますか。

    遠ざけると磁束が減るので、減少を妨げる（補う）ために、誘導電流は磁石の磁界と同じ向きの磁界をつくります。「いつも逆向き」と覚えていると「逆向き」を選んでしまいます。逆向きになるのは磁束が増えるときです。誘導電流がつくる磁界は、コイルを貫く磁束を増やしたり減らしたりする向き（コイルの軸に沿った向き）なので「垂直な向き」にはならず、磁束が変化している間は電流が流れるので「磁界はできない」も誤りです。
    標準問5O2

    水平に置いたコイルの真上から、S 極を下に向けた棒磁石を近づけます。コイルに流れる誘導電流の向きは、上から見てどちら回りですか。

    磁界は S 極に入る向きなので、磁石の下にあるコイルの中では上向きです。磁石が近づくので上向きの磁束が増加し、誘導電流は下向きの磁界をつくります。下向き（見ている人から遠ざかる向き）の磁界をつくる電流は、上から見て時計回りです。反時計回りと答えた人は、手順①で磁界の向きを下向きとした（S 極から出ると考えた）可能性があります。磁石が近づいている間は磁束が変化するので、「電流は流れない」は誤りです。
    標準問6O1・O2

    コイルを貫く磁束 Φ（右向きを正）が、下のグラフのように変化しました。誘導電流は「コイルの中に右向きの磁界をつくる向き」を正とします。0〜2 s と 2〜4 s の誘導電流の向きの組合せとして正しいものを選びなさい。

    0〜2 s は右向きの磁束が増えるので、誘導電流は左向きの磁界をつくる（負）。2〜4 s は磁束が 3×10⁻³ Wb のまま変化しないので、誘導電流は 0 です。「磁束が大きいから電流が流れ続ける（負・負）」は、磁束の値と変化を混同した誤りです。グラフの傾きの符号が向きを決め、傾きが 0 なら電流は流れません（傾きの大きさと起電力の大きさの関係は 物理-107 で学びます）。
    標準問7O2

    問6のグラフで、4〜7 s の誘導電流の向きはどうなりますか。この間、磁束は 5.5 s に 0 になり、その後は左向きになります。

    4〜5.5 s は右向きの磁束が減るので、減少を補う右向きの磁界（正）。5.5〜7 s は左向きの磁束が増えるので、増加を妨げる右向きの磁界（正）。どちらも右向きなので、ずっと正です。グラフでは傾きが負のまま変わらないことから分かります。磁束の向き（符号）が変わる瞬間に電流の向きも変わる、と考えるのは誤りです。
    入試問8O3

    N 極を下にした棒磁石を、水平に置いた閉じたコイルの真上から落とし、コイルの中を通過させます。磁石がコイルに近づく間と、通過して遠ざかる間に、磁石がコイルの誘導電流から受ける力の向きの組合せとして正しいものを選びなさい。

    誘導電流は磁石の動き（落下）を妨げるので、どちらの間も上向きの力です（例題3・図3）。近づく間はコイルの上面が N 極になって押し返し、遠ざかる間はコイルの下面が N 極になって磁石の上端の S 極を引き寄せます。電流の回り方は近づく間と遠ざかる間で逆になるので、「力も逆になる（上向き・下向き）」と考えがちですが、コイルに対する磁石の位置も上から下へ変わるため、力はどちらも上向きになります。近づく間に「下向き」（引き寄せる）とする選択肢は、誘導電流が変化を助けると考えた誤りで、エネルギー保存の法則に反します（問9）。
    入試問9O2・O3

    もしレンツの法則が「誘導電流は磁束の変化を助ける向きに流れる」というものだったとしたら、コイルに棒磁石を少し近づけただけで何が起こると考えられますか。その結果がエネルギーの観点から起こりえない理由とあわせて説明しなさい。

    解答例　磁束の増加を助ける向きに電流が流れると、コイルは近づく磁石を引き寄せる電磁石になる。磁石は引き寄せられて加速し、磁束の変化が速くなるので電流も大きくなり、さらに強く引き寄せられる。外から仕事をしなくても、磁石の運動エネルギーと回路で発生するジュール熱などの電気エネルギーが増え続けることになり、エネルギー保存の法則に反する。実際には誘導電流は変化を妨げる向きに流れ、磁石を動かすには外から仕事をする必要があり、その仕事が電気エネルギーになる。

    採点の観点　①「助ける」向きならコイルが磁石を引き寄せることを示している　②加速と電流の増加がくり返されることを示している　③外から仕事をしなくてもエネルギーが増え続けることを指摘している　④エネルギー保存の法則に反すると結論し、実際は外からの仕事が電気エネルギーになることに触れている。

    「レンツの法則はそう決まっているから」ではなく、エネルギーの保存という、より基本的な法則と結び付けて説明することが大切です。
    入試問10O2・O3

    同じ軸の上にコイル1とコイル2を並べます。コイル1には電池とスイッチ、コイル2には検流計をつなぎます。コイル1に電流を流している状態からスイッチを切った瞬間、コイル2に流れる電流の向きは、切る前のコイル1の電流の向きと比べてどうなりますか（同じ側から見た回り方で比べる）。

    スイッチを切るとコイル1の磁界が消え、コイル2を貫く磁束が減少します。減少を補うため、コイル2はコイル1と同じ向きの磁界をつくる、つまりコイル1と同じ回り方の電流が流れます（スイッチを入れた瞬間は逆向き）。電流が一定の間は磁束が変化しないので、スイッチを切る前のコイル2には電流は流れていません。
