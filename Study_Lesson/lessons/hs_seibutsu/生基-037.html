血糖濃度の調節と自律神経

授業1コマ（50分） 学習 共通テスト ○ † 教科書で一般的な内容を含む

朝ごはんを抜いた日の3時間目も、長距離走のゴール前も、血液中のグルコースの濃度（血糖濃度）は大きくは下がりません。体のどこが変化に気付き、どんな「連絡網」で肝臓に指令が届くのでしょうか。前の時間に学んだインスリン・グルカゴンに、自律神経とほかのホルモンを加えて、調節の全体像を組み立てます。

0この時間のねらい

この時間でできるようになること

  • O1血糖濃度を上げるホルモン（グルカゴン・アドレナリン・糖質コルチコイド）と下げるホルモン（インスリン）について、分泌する内分泌腺と、肝臓などでの働きを区別して説明できる。
  • O2血糖濃度の上昇・低下を間脳の視床下部が感知し、自律神経（副交感神経・交感神経）や脳下垂体を通じてホルモンの分泌を調節する経路を、図を使って説明できる。
  • O3血糖調節に関わる自律神経とホルモンの働きを示す資料（実験の結果）を読み取り、内分泌系とともに自律神経系が働くことで血糖濃度が一定の範囲に保たれていることを説明できる。

1前回までの確認

この時間は、次の3つの既習事項を組み合わせて使います。小問で確かめてから進みましょう。

確認1既習：生基-036

健康な人が食事をして血糖濃度が上がると、その後、血液中のインスリン濃度はどう変化しましたか。

食後に血糖濃度が上がると、それを追うようにインスリン濃度が上がり、血糖濃度が下がるとインスリン濃度も下がります（生基-036 の資料）。インスリンは血糖濃度を下げるホルモンです。「減少する」はグルカゴンの変化と取り違えています。
確認2既習：生基-031・生基-033

運動しているときや緊張しているときに主に働き、心臓の拍動を促進する神経はどれですか。

自律神経系は意識とは無関係に働き、交感神経と副交感神経があります（生基-031）。活動するときや緊張したときに働くのが交感神経で、拍動を促進します。副交感神経は休息しているときに働き、拍動を抑制します（生基-033）。運動神経は自律神経ではなく、意識して体を動かすときに筋肉へ指令を伝える神経です（中学校）。
確認3既習：生基-034

ホルモン分泌の中枢として働き、自律神経系の中枢でもある間脳の部分はどこですか。

間脳の視床下部は、ホルモン分泌の中枢として働き、自律神経系の中枢としても働きます。ホルモンの分泌量は、その働きの結果によって調節されます（フィードバック、生基-034）。この時間は、視床下部が血糖濃度の変化を感知して、神経とホルモンの両方に指令を出すことを学びます。

補足：グルコースは肝臓で「グリコーゲン」としてたくわえられる

中学校では、肝臓が栄養分をたくわえることを学びました（中2-059）。血液中のグルコース（ブドウ糖）が多いとき、肝臓ではグルコースがたくさんつながったグリコーゲンという物質がつくられてたくわえられます。血液中のグルコースが減ると、グリコーゲンが分解されてグルコースに戻り、血液中に出ていきます。筋肉もグリコーゲンをたくわえます。

名前が似ていますが、グリコーゲン＝たくわえられる物質、グルカゴン＝ホルモンです。

補足：視床下部の下にある「脳下垂体」

間脳の視床下部の下には、脳下垂体という内分泌腺がつながっています。脳下垂体は視床下部からの指令を受けて、ほかの内分泌腺に働きかけるホルモンなどを分泌します。脳下垂体には前葉と後葉があり、この時間に出てくるのは前葉です。

2導入：長く運動しても血糖濃度が下がりすぎないのはなぜ？

運動を続けると、筋肉は血液からグルコースを取り込んで呼吸に使います。それでも健康な人の血糖濃度は、およそ 0.1％（血液 100 mL あたり約 100 mg）前後の一定の範囲に保たれます。血液中のグルコースは全身の細胞のエネルギー源なので、血糖濃度が下がりすぎると、脳などの働きに影響が出るとされています（詳しくは教科書で確かめよう）。

予想してみよう

① 血糖濃度が下がったことに、体のどこが気付くのでしょうか。

② 前の時間に学んだグルカゴンのほかに、血糖濃度を上げるしくみはあるでしょうか。神経は関わっているでしょうか。

ヒント：運動中や緊張したとき、心臓の拍動を速めたのは何でしたか（確認2）。

3血糖濃度を変えるホルモンと、それを出す場所

血糖濃度を変えるホルモンの多くは、肝臓に働きます。肝臓は、グルコースをグリコーゲンとしてたくわえたり（合成）、グリコーゲンを分解してグルコースを血液中に出したり（分解）する、いわば「グルコースの貯金箱」です。どちらの向きに進めるかを、ホルモンが切り替えています。

血糖濃度に関わる主なホルモンを表にまとめます。すい臓の中には、内分泌細胞が島のように集まったランゲルハンス島があり、その中のA細胞がグルカゴンを、B細胞がインスリンを分泌します（A細胞は、教科書によっては「参考」の図などで扱われます）。腎臓の上にある副腎は、内側の髄質と外側の皮質で、別のホルモンを分泌します。

ホルモン分泌する内分泌腺（細胞）主な働き血糖濃度
インスリンすい臓のランゲルハンス島の B細胞肝臓や筋肉などの細胞にグルコースを取り込ませ、肝臓でグリコーゲンの合成を促進する下げる
グルカゴンすい臓のランゲルハンス島の A細胞肝臓でグリコーゲンの分解を促進する上げる
アドレナリン副腎髄質肝臓などでグリコーゲンの分解を促進する（心臓の拍動も促進する：生基-033）上げる
糖質コルチコイド副腎皮質タンパク質などから糖（グルコース）をつくる反応を促進する上げる

下げるのは1つ、上げるのは複数

血糖濃度を下げるホルモンはインスリンだけです。一方、上げるホルモンはグルカゴン・アドレナリン・糖質コルチコイドなど複数あります。「下がりすぎると困るので、下がったときに備えるしくみが何重にも用意されている」と考えると覚えやすくなります。

よくある間違い

「インスリンはグルコースを分解して減らす」は誤りです。インスリンは、グルコースを細胞に取り込ませることと、肝臓でグリコーゲンにしてたくわえさせることで、血液中のグルコースを減らします。グルコースそのものがなくなるわけではありません（取り込まれたグルコースは呼吸などに使われます）。

4自律神経はどう関わる？――高血糖のとき・低血糖のとき

血糖濃度の変化は、主に2か所で感知されます。1つは間脳の視床下部で、血液が運ぶグルコースの濃度の変化を感知し、自律神経とホルモンの両方を使って指令を出します。もう1つはすい臓のランゲルハンス島で、A細胞・B細胞は血糖濃度の変化を直接感知してホルモンの分泌量を変えます。

血糖濃度が上がったとき（食後など）

食後に血糖濃度が上がると、B細胞が直接それを感知してインスリンを分泌します。同時に視床下部も上昇を感知し、副交感神経を通じて B細胞にインスリンの分泌を促します。インスリンは血液で全身に運ばれ、肝臓でのグリコーゲンの合成や、細胞へのグルコースの取り込みを促進します。こうして血糖濃度が下がります。

血糖濃度が下がったとき（空腹時・運動時など）

血糖濃度が下がると、A細胞が直接それを感知してグルカゴンを分泌します。視床下部も低下を感知し、次の2つの道筋で血糖濃度を上げる指令を出します。

  • 自律神経の道筋（速い）：交感神経を通じて副腎髄質に働き、アドレナリンを分泌させます。交感神経はすい臓の A細胞にも働き、グルカゴンの分泌を促します（この経路は、教科書によっては図に示されていません）。どちらのホルモンも肝臓のグリコーゲンの分解を促進します。
  • ホルモンの道筋（ゆっくり・持続的）：視床下部がホルモンで脳下垂体前葉に働きかけ、脳下垂体前葉から出るホルモンが副腎皮質に働いて、糖質コルチコイドを分泌させます。糖質コルチコイドは、タンパク質などから糖をつくる反応を促進します。

神経が「ホルモンの蛇口」を開け閉めする

血糖濃度の調節では、自律神経が肝臓に直接命令するのではなく、自律神経が内分泌腺（すい臓・副腎髄質）に働いてホルモンの分泌量を変え、そのホルモンが血液で運ばれて肝臓などに働きます。副交感神経は下げる向き（インスリン）、交感神経は上げる向き（アドレナリン・グルカゴン）に働きます。血糖濃度が元の範囲に戻ると、変化の感知が弱まり、ホルモンの分泌も元に戻ります（フィードバック）。

例題1　経路を順にたどる

空腹が続いて血糖濃度が下がったとき、「自律神経を通る経路」で肝臓のグリコーゲンが分解されるまでを、順に並べなさい。

ステップ1：変化を感知するのはどこか → 間脳の視床下部。
ステップ2：上げる向きに働く自律神経はどちらか → 活動するときに働く交感神経（副交感神経は下げる向き）。
ステップ3：交感神経が働きかける内分泌腺と、分泌されるホルモン → 副腎髄質からアドレナリン（すい臓の A細胞からグルカゴンも）。
ステップ4：答え　血糖濃度の低下 → 視床下部 → 交感神経 → 副腎髄質 → アドレナリン（血液で運ばれる）→ 肝臓でグリコーゲンの分解 → 血糖濃度が上がる。

よくある間違い

「副交感神経がインスリンを分泌する」は誤りです。インスリンを分泌するのはすい臓の B細胞で、副交感神経は B細胞に分泌を促すだけです。同じように、アドレナリンを分泌するのは交感神経ではなく副腎髄質です。「どこが感知し、何が伝え、どこが分泌し、どこに働くか」を分けて考えましょう。

5資料で確かめる：副腎髄質を除くと、低血糖からの回復はどうなるか

「交感神経 → 副腎髄質 → アドレナリン」の道筋は、本当に血糖濃度を上げるのに役立っているのでしょうか。動物を使った実験の結果（資料）から確かめます。

実験：低血糖からの回復と副腎髄質（学習用の架空のデータ）

目的　インスリンを注射して血糖濃度を下げたとき、血糖濃度が元に戻る過程に副腎髄質（アドレナリン）が関わっているかを調べる。

方法　同じ系統・同じ週齢のラットを同じ時間絶食させ、4つの群に分ける。副腎髄質を取り除く群と、取り除かない群をつくる（取り除かない群にも、切開して縫い合わせるだけの同じ手術の操作をして、手術による負担をそろえる）。それぞれに、インスリン溶液または生理食塩水を同じ量注射し、30分ごとに血糖濃度を測定する。

群副腎髄質注射したものねらい
Aあり（切開の操作のみ）生理食塩水対照（手術と注射の操作だけの影響を見る）
Bあり（切開の操作のみ）インスリンインスリンの影響を見る

条件をそろえたもの　ラットの系統・週齢・絶食時間、注射する液の量と時刻、測定の方法、飼育室の温度。各群とも複数匹の平均値で比べる。

例題2　結果を「1か所だけ違う組」で比べて読み取る

表と図4から、どの群とどの群を比べると何が分かるかを考えなさい。

ステップ1：A と B（違いはインスリンだけ）　B は30分後に 52 まで下がった → インスリンは血糖濃度を下げる。その後 B は 120 分後に 89 まで戻った → 体には血糖濃度を上げるしくみが働いている。
ステップ2：A と D（違いは副腎髄質の有無だけ。どちらも同じ手術の操作を受け、生理食塩水を注射）　どの時刻も差は 2 以内 → 副腎髄質を除いても、低血糖にしていないときの血糖濃度はほとんど変わらない。だから C の結果の違いを「もともと血糖濃度が低かったから」とは考えにくい。
ステップ3：B と C（違いは副腎髄質の有無だけ）　C は 30 分後に 46 まで下がり、30→120 分の上昇量は C が 74 − 46 ＝ 28、B が 89 − 52 ＝ 37 → 副腎髄質がないと回復が遅い。副腎髄質（アドレナリン）は血糖濃度を上げるのに関わっている。
ステップ4：C だけを見る　副腎髄質がなくても 46 から 74 まで回復している → 副腎髄質以外にも上げるしくみ（A細胞のグルカゴン、副腎皮質の糖質コルチコイドなど）がある。副腎髄質のアドレナリンは交感神経の指令で分泌されるので、この結果は、内分泌系とともに自律神経系が血糖濃度の維持に働いていることを支持する。

読み取りの注意

「C は回復が遅い」から「血糖濃度を上げるのはアドレナリンだけだ」と結論するのは言い過ぎです（C も回復しています）。また、この実験だけでは「交感神経が副腎髄質に働いていること」そのものは確かめていません。それを確かめるには、交感神経の働きだけを変えた群を別に比べる必要があります（確認問題の問8）。結論は、比べた条件の違いが示す範囲にとどめましょう。

6神経とホルモンの連携と、よくある誤解

血糖濃度の調節では、神経系と内分泌系が役割を分けながら協力しています。生基-034 で学んだ「神経系は速く、内分泌系は持続的」という特徴が、ここでも生きています。

自律神経（神経系）ホルモン（内分泌系）
伝わり方神経を通って、つながっている器官に直接伝わる血液で全身に運ばれ、そのホルモンを受け取る標的器官に働く
速さ・続き方速いが、効果は短い比較的ゆっくりだが、効果が持続する
血糖調節での役目視床下部の指令をすい臓・副腎髄質にすばやく伝え、ホルモンの分泌量を変える肝臓や全身の細胞に働いて、グルコースの出し入れを実際に変える

誤解を直そう

よくある誤解正しくは
グルカゴンは肝臓にたくわえられる物質だたくわえられるのはグリコーゲン。グルカゴンは A細胞が分泌するホルモンで、グリコーゲンの分解を促進する。
副交感神経がインスリンを出す／交感神経がアドレナリンを出す分泌するのは B細胞・副腎髄質。自律神経はそれらの内分泌腺に分泌を促す。
交感神経は体を興奮させるので、血糖濃度を下げる交感神経は活動に備える向きに働き、アドレナリンやグルカゴンの分泌を促して血糖濃度を上げる。
血糖濃度はいつも同じ値に固定されている食後には上がり、空腹時や運動時には下がろうとする。調節によって一定の範囲に戻される（生基-036 の資料）。
血糖濃度の調節はホルモンだけで行われ、神経は関係ない視床下部が自律神経を通じてホルモンの分泌を調節しており、神経系と内分泌系の両方が働く（例題2）。

よくある間違い：上げるしくみと下げるしくみの数

「インスリンが足りなくても、代わりに血糖濃度を下げるホルモンがある」と考えるのは誤りです。下げる向きに働くホルモンはインスリンだけなので、インスリンが十分に働かないと血糖濃度が高いままになります。これが次の時間に学ぶ糖尿病につながります。

7重要語句

この時間の重要語句

血糖濃度
血液中のグルコース（ブドウ糖）の濃度。健康な人ではおよそ 0.1％ 前後の範囲に保たれる。
グリコーゲン
多数のグルコースがつながった物質。肝臓や筋肉にたくわえられ、分解されるとグルコースに戻る。
ランゲルハンス島（A細胞・B細胞）
すい臓の中で内分泌細胞が島状に集まった部分。A細胞はグルカゴン、B細胞はインスリンを分泌する。どちらも血糖濃度の変化を直接感知する。
インスリン
B細胞が分泌するホルモン。細胞へのグルコースの取り込みと肝臓でのグリコーゲンの合成を促進し、血糖濃度を下げる。血糖濃度を下げるホルモンはこれだけ。
グルカゴン
A細胞が分泌するホルモン。肝臓でグリコーゲンの分解を促進し、血糖濃度を上げる。
副腎（髄質・皮質）
腎臓の上にある内分泌腺。内側の髄質からアドレナリン、外側の皮質から糖質コルチコイドなどが分泌される。
アドレナリン
副腎髄質が分泌するホルモン。交感神経の指令で分泌が増え、肝臓でグリコーゲンの分解を促進して血糖濃度を上げる。
糖質コルチコイド
副腎皮質が分泌するホルモン。脳下垂体前葉のホルモンによって分泌が促され、タンパク質などから糖をつくる反応を促進して血糖濃度を上げる。
視床下部
間脳の一部。自律神経系とホルモン分泌の中枢で、血糖濃度の変化を感知する。
脳下垂体（前葉）
視床下部の下にある内分泌腺。視床下部の指令を受けて、ほかの内分泌腺に働くホルモンなどを分泌する。
交感神経・副交感神経
自律神経。血糖調節では、交感神経が副腎髄質・A細胞に働いて血糖濃度を上げる向きに、副交感神経が B細胞に働いて下げる向きに働く。
フィードバック
働きの結果が、元の働きの強さを調節すること。血糖濃度が元の範囲に戻ると、ホルモンの分泌も元に戻る。

8まとめ

この時間のまとめ

  • 血糖濃度を下げるホルモンはインスリン（B細胞）だけ。上げるホルモンはグルカゴン（A細胞）・アドレナリン（副腎髄質）・糖質コルチコイド（副腎皮質）など複数ある。多くは肝臓のグリコーゲンの合成・分解を切り替える。（O1）
  • 血糖濃度の変化は視床下部とランゲルハンス島が感知する。高血糖では副交感神経が B細胞に、低血糖では交感神経が副腎髄質と A細胞に働き、視床下部は脳下垂体前葉を通じて副腎皮質にも働きかける。（O2）
  • 自律神経は内分泌腺に働いてホルモンの分泌量を変え、ホルモンが血液で運ばれて肝臓などに働く。神経系（速い）と内分泌系（持続的）が協力して、血糖濃度を一定の範囲に保つ。（O2・O3）
  • 資料は「1か所だけ条件が違う組」を比べて読む。副腎髄質を除くと低血糖からの回復が遅れるが回復はする → アドレナリンは関わるが、ほかのしくみもある。（O3）
高血糖のとき（下げる）

視床下部 →（副交感神経）→ すい臓 B細胞 → インスリン → 肝臓：グリコーゲン合成／細胞：グルコース取り込み

低血糖のとき（上げる）

視床下部 →（交感神経）→ 副腎髄質 → アドレナリン／A細胞 → グルカゴン → 肝臓：グリコーゲン分解
視床下部 → 脳下垂体前葉 → 副腎皮質 → 糖質コルチコイド → タンパク質などから糖

9確認問題

基本 → 標準 → 入試レベルの順。各問に対応するねらい（O番号）を示す。問6〜8 は「資料で確かめる」の実験（架空のデータ）を使う。

基本問1O1

インスリンを分泌する細胞はどれですか。

インスリンは B細胞、グルカゴンは A細胞が分泌します。副腎髄質はアドレナリン、脳下垂体前葉は副腎皮質に働くホルモンなどを分泌します。A と B を取り違えやすいので、「B細胞は血糖を下げる（インスリン）」と結び付けて覚えましょう。
基本問2O1

次のうち、血糖濃度を上げる働きをもたないホルモンはどれですか。

インスリンは血糖濃度を下げる唯一のホルモンです。グルカゴンとアドレナリンは肝臓でグリコーゲンの分解を、糖質コルチコイドはタンパク質などから糖をつくる反応を促進して、血糖濃度を上げます。
基本問3O2

血糖濃度が下がったとき、視床下部からの指令を副腎髄質に伝え、アドレナリンの分泌を促す神経はどれですか。

血糖濃度を上げる向きに働くのは交感神経です。副交感神経は B細胞に働いてインスリンの分泌を促す、下げる向きの神経です。感覚神経・運動神経は自律神経ではありません。
標準問4O1

肝臓で、多数のグルコースがつながった形でたくわえられ、グルカゴンやアドレナリンの働きで分解される物質の名前をカタカナで答えなさい。

答えはグリコーゲンです。「グルカゴン」と答えた人は、ホルモン（グルカゴン）とたくわえられる物質（グリコーゲン）を取り違えています。インスリンはグリコーゲンの合成を、グルカゴン・アドレナリンは分解を促進します。
標準問5O2

食後に血糖濃度が上がったとき、神経を通る経路で血糖濃度が下がるまでの順として正しいものはどれですか。

高血糖を感知した視床下部は、副交感神経を通じてすい臓の B細胞にインスリンの分泌を促します。インスリンは血液で運ばれ、肝臓でのグリコーゲンの合成や細胞へのグルコースの取り込みを促進します。1つ目は交感神経・副腎髄質（上げる向きの経路）と混ざっています。3つ目は「神経がインスリンを分泌する」誤りです。4つ目は感知と指令の向きが逆で、しかも A細胞はインスリンではなくグルカゴンを分泌する細胞です。
標準問6O3

実験の表で、群 B（副腎髄質あり＋インスリン）の血糖濃度は、注射30分後から120分後までに何 mg/100 mL 上昇しましたか。数値で答えなさい。

mg/100 mL
30分後が 52、120分後が 89 なので、89 − 52 ＝ 37（mg/100 mL）です。0分からの変化（92 → 89 で −3）と混同しないようにしましょう。同じように計算すると群 C は 74 − 46 ＝ 28 で、C のほうが回復が小さいことが数値でも確かめられます。
入試問7O3

実験の結果から判断できることとして、最も適当なものはどれですか。

B と C（違いは副腎髄質だけ）の比較で C の回復が遅いので、副腎髄質は回復に関わります。一方、C も 46 から 74 まで回復しているので、ほかのしくみも働いています。1つ目は A と D の比較（差は2以内）に反します。3つ目は C が回復していることと矛盾し、グルカゴンを測っていないので「働いていない」とも言えません。4つ目は、この実験では調べていない内容です。
入試問8O2・O3

次に、「交感神経の働きが低血糖からの回復に関わるか」を調べたい。群 B（副腎髄質あり＋インスリン）と比べる群として、最も適当なものはどれですか。

調べたい条件（交感神経の働き）だけを群 B と変えた群が必要です。2つ目は交感神経と注射の中身の2つが、4つ目は交感神経と絶食の2つが違うので、差の原因を1つに決められません。3つ目は交感神経の働きを変えていません。群 B も切開して縫い合わせる操作を受けているので、1つ目の群と比べれば「手術の操作そのもの」の影響もそろえられます。
入試問9O2・O3

健康な人が90分間、軽い運動を続けたときの血液中の値を調べた（学習用の架空のデータ。運動開始時を 100 とした相対値）。

運動開始からの時間（分）0306090
血糖濃度100989796
インスリン濃度100705545
グルカゴン濃度100130160190
アドレナリン濃度100200300380

筋肉がグルコースを使い続けているのに血糖濃度がほとんど変わらない理由を、表の3つのホルモンの変化と、自律神経の働きに触れて100字程度で説明しなさい。

解答例　血糖濃度の低下を視床下部が感知し、交感神経を通じて副腎髄質のアドレナリンとすい臓A細胞のグルカゴンの分泌が増えて、肝臓でグリコーゲンの分解が進む。一方、インスリンの分泌は減るので、血糖濃度はほぼ一定に保たれる。（105字）

採点の観点　①グルカゴン・アドレナリンの増加を、肝臓のグリコーゲン分解（グルコースの放出）と結び付けている。②インスリンの減少を書いている。③交感神経が副腎髄質（や A細胞）に働くことに触れている。④視床下部が血糖濃度の低下を感知することに触れている（あればよい）。

90分で血糖濃度は 4％ しか下がっていないのに、グルカゴンは 1.9 倍、アドレナリンは 3.8 倍に増え、インスリンは半分以下（45）に減っています。上げるホルモンが増え、下げるホルモンが減る――この組合せで血糖濃度が保たれています。「アドレナリンが筋肉にグルコースを与える」のように、ホルモンが直接グルコースになるかのように書くのは誤りです。
