## 1. 目的と成果物の定義

### 1.1 目的

高校受験と大学受験を想定し、中学・高校の学習内容の全容を、**大項目＝教科・科目／中項目＝単元／小項目＝授業1コマ（50分）**に分類して一覧にする。内容は公的資料を根拠にし、ハルシネーション（根拠のない記述）と内容の誤りを避ける。完成後は、コマごとの学習コンテンツ（教材・問題）の生成と、子どもの学習支援に使う。

### 1.2 対象範囲

| 区分 | 範囲 | 入試の想定 |
|---|---|---|
| 中学校 | 5教科（国語・社会・数学・理科・英語）の全学年 | 千葉県公立高等学校入学者選抜（学力検査） |
| 高等学校 | 大学入試で出題されうる全科目（共通テストの出題科目＋個別試験で使われる科目） | 大学入学共通テスト（令和9年度）＋個別試験（大学は未指定） |

## 3. 根拠資料と優先順位

### 3.1 資料の優先順位

1. **学習指導要領 本文**（内容の範囲・記号・内容の取扱い）
2. **学習指導要領解説**（内容の具体、例示、系統、扱いの程度）
3. **入試の公式資料**（共通テスト実施要項・問題作成方針、千葉県の出題方針・実施要項）

使わない資料：学校や個人のサイト、会員登録・パスワードが必要な資料、出典の分からない二次情報、記憶による補完。

### 3.3 入試資料から確定している事項

**共通テスト（令和9年度実施要項・問題作成方針）**

- 出題範囲の原則：「出題範囲について特記がない場合，出題科目名に含まれる学習指導要領の科目の内容を総合した出題範囲とする」。
- 『数学Ⅰ，数学A』：数学A は「図形の性質」「場合の数と確率」（全て解答）。「数学と人間の活動」は範囲外（本資料では別枠・「—」）。
- 『数学Ⅱ，数学B，数学C』：数学B・C の「数列」「統計的な推測」「ベクトル」「平面上の曲線と複素数平面」の4項目から3項目を選択。数学Bの「数学と社会生活」、数学Cの「数学的な表現の工夫」は範囲外（別枠・「—」）。
- 『国語』：「現代の国語」「言語文化」。近代以降の文章3問（110点）、古典2問（90点）。論理国語・文学国語・古典探究は範囲外（「—」）。
- 『英語』：リーディングとリスニング。英語コミュニケーションⅠ・Ⅱと論理・表現Ⅰの範囲。英語コミュニケーションⅢ、論理・表現Ⅱ・Ⅲは範囲外（「—」）。
- 『情報Ⅰ』：60分・100点。
- 地理歴史・公民：『地理総合，地理探究』『歴史総合，日本史探究』『歴史総合，世界史探究』『公共，倫理』『公共，政治・経済』『地理総合／歴史総合／公共』（3つの範囲から2つを選択）。組合せの制約は実施要項の注の原文による。
- 理科：『物理基礎／化学基礎／生物基礎／地学基礎』（4つの範囲から2つを選択、1科目扱い）、『物理』『化学』『生物』『地学』。専門科目の出題範囲に基礎科目は含まれない（特記なし）。問題作成方針は専門科目について「基礎を付した科目の内容との関連も考慮する」とする。
- 数学Ⅲ は範囲外（「—」）。

### 3.4 教科書会社の資料の使い方

- **語句の確認**：† を付けて補う教科書レベルの語句の出典。本文扱いであることを確認する（「発展」「参考」「コラム」扱いは不可）。

## 4. データモデル

### 4.1 フォルダー構成

| 場所 | 中身 |
|---|---|
| `data/` | 資料の本体。**唯一の正本**。`common.py` が欄の定義 |
| `output/*.md` | 人が読む資料（生成物。直接編集しない） |
| `output/00_一覧.md` | 目次（生成物） |
| `output/json/` | AI・プログラム向け（生成物）：`<モジュール名>.json`、`all_rows.jsonl`、`units.jsonl` |
| `sources/` | 根拠資料：`raw/`（PDF）、`text/`（抽出テキスト。`=== PDF p.N ===` 区切り）、`registry/`（取得記録）、解説の見出し対応表（`*_kaisetsu_headings.tsv`）など |
| `tools/` | 共通ツール（5.節と 7.節） |
| `tools/checks/` | 語句と出典の照合スクリプト（`run_all.py` でまとめて実行） |
| `tools/worker/` | 作業担当の一回限りのスクリプト（経緯の記録。動作は保証しない） |
| `docs/` | 本書、AI 保守ガイド、作業要領 |
| `reports/` | `lint.md`（横断点検）、`review/`（資料ごとの見直しの記録）、`checks/`（照合の詳細） |
| `backup/` | 大きな変更の前の `data/` の控え |

### 4.2 データの型（`data/common.py`）

```python
Segment(key, title, hours, row_label, no_prefix, kaisetsu_pages=(開始, 終了))
Unit(uid, seg, title, cos, kaisetsu, publishers, rows=[...], note="", exam={}, extra=False, aim="", prereq=[])
R(title, kind, summary, basis, page="", mark="", exam={}, rid="")
```

| 型・欄 | 意味 |
|---|---|
| Segment.key | 区分のキー（中学は学年の数、高校は科目名など） |
| Segment.title / hours | 区分名／標準時数（行数の合計がこれに一致する） |
| Segment.row_label / no_prefix | 表の「学年・科目」欄の表示／行IDの接頭辞 |
| Segment.kaisetsu_pages | 解説でその区分の内容が書かれた印刷ページの範囲（見出し照合用） |
| Unit.uid | 単元ID（資料内で一意。例 `1-3`、`Ⅰ-2`、`B-3(ウ)`、`地総-6`） |
| Unit.seg | 所属する区分のキー |
| Unit.title / cos / kaisetsu | 単元名／学習指導要領の該当箇所の表示／解説の該当ページの表示 |
| Unit.publishers | 教科書会社のキー→配当時数（読み取れたものだけ。無ければ `{}`） |
| Unit.note | 単元の注（配当時数の対応付け、並べ方の理由、解説の問いの例など） |
| Unit.exam | 単元の入試の印の既定値（行で上書き可） |
| Unit.extra | True なら標準時数の合計に含めない別枠単元 |
| Unit.aim | 単元のねらい（1〜2文） |
| Unit.prereq | 前提となる単元の参照（同じ資料は `uid`、別の資料は `<モジュール名>:<uid>`） |
| R.title | 小項目名（1コマ） |
| R.kind | 区分（5.4） |
| R.summary | 学習内容の要点（5.3） |
| R.basis | 学習指導要領の根拠コードのリスト（4.4） |
| R.page | 解説の印刷ページ（`"66"`、`"84-85"`） |
| R.mark | `"†"` または空（5.5） |
| R.exam | 入試の列名→印（単元・資料の既定値を上書きするときだけ） |
| R.rid | 資料内で固定の行ID（4.5） |

### 4.3 資料ごとの設定（モジュールの大文字の変数）

必須：`SUBJECT`、`SCHOOL`、`COS_NAME`、`KAISETSU_NAME`、`HEADINGS_TSV`、`SEGMENTS`、`COS_ITEMS`、`TERMS`、`EXAM_COLUMNS`、`EXAM_DEFAULT`、`BASIS_NOTE`、`EXAM_NOTE`、`HEADER_LINES`、`LIMITATIONS`、`PUBLISHER_NAMES`、`SOURCES`、`UNITS`。任意：`KAISETSU_EXTRA`（(区分キー, コード)→ページの手入力）、`SHARED_PAGES`、`PUBLISHER_NOTE`、`METHOD_NOTE`、`FETCHED`、`EXAM_NOTES`（列ごとの注）。語句を補った資料は語句と出典の対応表（`TEXTBOOK_TERMS`、`SOURCE_TEXTS`、`TERM_ADDITIONS` など）を持つ。

- `COS_ITEMS[区分キー]`：学習指導要領本文の内容の全項目（下位記号まで）と、内容を追加・限定・指定する内容の取扱い。一般的な配慮だけの取扱いは入れない。網羅の検証に使う。
- `TERMS[区分キー]`：本文の〔用語・記号〕の全語（数学など）。無ければ空。
- `SOURCES`：`(ID, 資料名, 発行者, URL, 用途)` のリスト。
- `EXAM_COLUMNS` / `EXAM_DEFAULT`：中学は `["高校入試（千葉県）"]` / `{"高校入試（千葉県）": "○"}`。高校は `["共通テスト", "個別試験"]` / `{"共通テスト": "○", "個別試験": ""}`（共通テストの範囲外の科目は `"—"`）。

**実行時に要点へ語句を書き足す資料**：地理（hs_chiri）・歴史総合（hs_rekishisogo）・世界史探究（hs_sekaishi）は、行の要点の本文と、末尾の「主な語句：…。［語句：S番号］」を別に持ち、読み込み時に対応表から語句を書き足して † を付ける。語句の変更は対応表で行う。

### 4.4 根拠コードの書式

学習指導要領本文の記号体系をそのまま使う（全角カタカナ、半角括弧）。

| 教科・学校 | 例 | 注 |
|---|---|---|
| 中学 数学・社会 | `A(1)ア(ア)`、`B(1)イ(イ)` | 内容の取扱いは `取扱い(1)`、課題学習は `第3の4` |
| 中学 理科 | `1分野(1)ア(ア)㋐`、`2分野取扱い(4)オ` | 分野を頭に付ける |
| 中学 国語 | `A(1)ア`、`B(1)イ`、`C(1)ウ`、`知(1)ア`、`知(3)エ(ア)` | 第3の2（内容の取扱い）は `取扱い(1)ウ(エ)`、第3の1は `第3の1(4)`、第3の3は `第3の3(3)` |
| 中学 英語 | `(1)エ(イ)b(a)`、`(1)エ(ウ)k`、`(3)①イ(エ)`、`(3)②イ(ア)` | 全角のａ〜ｋ・⒜〜⒟は半角で書く。3 指導計画の作成と内容の取扱いは `取扱い(2)エ(ア)` |
| 高校 多くの科目 | `(1)ア(ア)` | 大項目がある科目は `A(1)ア(ア)`、下位記号は `(1)ア(ア)㋐` |
| 高校 共通 | `取扱い(1)`、`取扱い(2)ア`、`課題学習` | |
| 区分をまたぐ参照 | `2:D(2)ア(イ)`、`数学A:(2)ア(ウ)` | `<区分キー>:<コード>` |

`build_md.py` が、全コードが `COS_ITEMS` に存在すること（誤記なし）と、`COS_ITEMS` の全項目がどこかの行に使われていること（網羅）を検証する。

### 4.5 ID の体系

- **行ID（rid）**：`<区分の接頭辞>-<3桁の番号>`（例 `中1-066`、`物基-012`）。資料内で一意。
  - 行を追加・削除・並べ替えしても**他の行の ID は変えない**。
  - 削除した ID は欠番にし、再利用しない。
  - 新しい行は rid を書かずに追加し、`tools/assign_ids.py` が区分内の最大番号の次から振る（並び順と番号が一致しないことがある）。
- **全体で一意の ID**：`<モジュール名>/<rid>`（例 `jhs_math/中1-001`）。コマごとの教材、学校別の授業計画、大学別の印などはこの ID で行を参照する。
- **単元の参照**：`<モジュール名>:<uid>`（例 `jhs_math:3-4`）。

### 4.6 JSON 版の項目

`output/json/all_rows.jsonl`（1行＝1コマ＝1レコード。単独で文脈が分かる）

| 項目 | 内容 |
|---|---|
| id / rid | 全体ID／資料内ID |
| map, map_title, school, subject, segment, segment_hours | 資料・学校・教科科目・区分・標準時数 |
| unit_ref, unit_title, unit_aim, unit_prereq, unit_extra | 単元の参照・名称・ねらい・前提単元・別枠か |
| order_in_segment, order_in_unit, prev_id, next_id | 並び順・前後のコマ |
| title, kind | 小項目名・区分 |
| summary | 要点（原文） |
| summary_core, key_terms, term_sources | 要点から「主な語句」と出典の印を分けたもの |
| basis, basis_text, kaisetsu_page | 根拠コード・表示・解説ページ |
| dagger | † の行か |
| exam | 入試の列名→印 |

`output/json/<モジュール名>.json` は資料1つ分で、上記に加えて資料の注（header、basis_note、method_note、exam_columns と注、limitations）、`sources`、区分ごとの `cos_items`（学習指導要領の全項目）と `required_terms`（〔用語・記号〕）、単元ごとの教科書会社の配当時数を持つ。`units.jsonl` は全単元の一覧。

## 5. 内容のロジック（決め方）

### 5.1 コマ数

1. 区分の合計＝標準時数（中学：学校教育法施行規則 別表第二、高校：標準単位数×35）。社会は分野の時数（地理115・歴史135・公民100。学習指導要領の指導計画の作成と内容の取扱い）。
2. 単元のコマ数は、教科書会社の配当時数の最小〜最大の範囲に収める（`build_md.py` の検証5）。
3. 教科書会社の計画の合計が標準時数より少ない差分（予備時間）は、「復習（予備時間）」単元にし、**範囲を明示した復習のコマ**にする。復習のコマ数は各社の予備時間（標準時数と各社の合計の差）の範囲に収める。例：中学数学3年は各社の予備 21〜28 の範囲、中学英語3年は各社の差 45〜52 の範囲、中学国語3年は各社の予備 0〜5 の上限の 5。中学3年の復習単元には高校入試に向けた3年間の総復習を含める（総復習もこの範囲の中で行う）。
4. 学習指導要領が内容を「適宜選択させる」科目（数学A・B・C）は、共通テストの出題範囲の内容を標準時数に充て、それ以外の内容は `extra=True` の別枠単元（各30コマ）にする。
5. 行を追加するときは、同じ単元の中で統合・削除してコマ数を保つ。

### 5.2 小項目の立て方

- 1行＝授業1コマで扱える量。関係の薄い内容を1行に詰めない（例：漢文の句法6種を2コマに分けた）。同じ内容の行を重複させない。
- 学習指導要領の事項と解説の記述を単位にし、教科書会社の配列・配当を参考にする。
- 国語・英語は学習指導要領の事項で立て、教科書の教材名・作品名に依存しない。作品名は解説に例示のあるものだけ。
- 単元の中は「学習→活用→演習」の順。復習は単元または区分の最後。
- 単元の並びは学習の系統に合わせる。教科書会社の配列と違う場合や学習指導要領の記載順と違う場合は、単元の注に理由を書く。
- 同じ資料の中で同名の行を作らない（演習・復習は範囲を名前に入れる）。

### 5.3 要点の書き方

- 1文目：そのコマの中心内容（何を・どこまで）と到達目標。文末は到達が分かる形（「〜を理解する」「〜を求めることができる」「〜を見いだす」「〜を説明する」など）。
- 2文目以降（任意）：扱う例・場面・活動、注意点。例は解説にあるものを優先。
- 「理解を深める」「考える」「取り上げる」「扱う」「触れる」だけで終わり、何を身に付けるか分からない書き方をしない（「触れる」は扱いの程度を示す語として2文目に残してよい）。
- 演習・練習・復習の行は、扱う問題の型と範囲を書く（例：「度数分布表・ヒストグラム、範囲と代表値…の読み取りと比較…の問題に取り組み」）。
- 計算を伴う行は、求める量と使う関係・式を書く（例：「PV＝nRT」「写像公式 1／a＋1／b＝1／f」）。
- 教科書の語句を補った行は、末尾を「主な語句：A、B、C。［語句：S12］」にする（語句ごとに出典が違う場合は［A：S8、B：S11］）。
- 長さの目安：出典の印と末尾の「主な語句」を除いた本文で 40〜180 字。1概念の行で内容が明確なら 25 字以上でよい。220 字超は要点を先にして整理する。**字数の目安は内容の正確さ・網羅より優先しない**（必要な事項を削らない。超える場合は理由を記録に書く）。
- 文体は簡潔な常体。

### 5.4 区分（kind）

| 区分 | 意味 | 入試の既定の扱い |
|---|---|---|
| 学習 | 新しい内容 | 資料の既定値 |
| 活用 | 問題解決・具体的な場面での活用 | 資料の既定値 |
| 演習 | 練習・単元末問題 | 資料の既定値 |
| 実験 | 観察・実験（理科） | 資料の既定値 |
| 探究 | 課題を設定して調べ、考察・構想・表現する探究的な学習（地歴公民・理科） | 資料の既定値 |
| 復習 | 予備時間を充てた復習 | 資料の既定値 |
| 実習 | 実習（プログラミングなど） | 「—」（範囲内なら行で指定） |
| 課題学習 | 学習指導要領が位置付けを求める課題学習（数学） | 「—」（範囲内なら行で指定） |

国語の探究的な行も「学習」「活用」を使う（「探究」は地歴公民・理科用）。

### 5.5 † と出典

† は「教科書で一般的に扱うが、解説に明示の記述が見当たらない語句・内容を含む行」の印。3種類ある。

| 種類 | 対象 | 出典の表記 |
|---|---|---|
| A 内容の† | 解説に明記はないが教科書で一般的な内容（例：数学の典型問題、理科の法則名） | 不要（† だけ） |
| B 語句の† | 補った教科書レベルの語句（人名・年号・用語・法則名など） | 必須。教科書会社の公開資料で確認し、要点末尾に「主な語句：…。［語句：S番号］」、資料を `SOURCES` に追加 |
| C 制度の† | 制度・機関・法令に関する事実（選挙制度、国会・内閣・裁判所の仕組み、中央銀行の政策手段、国際機関の仕組み、社会保障制度など） | 必須。法令の条文（e-Gov）や所管の公的機関の一次資料で確認し、B と同じ書式 |

- † の行は削らない。
- 解説に記述がある語は † なしで書いてよい（表記ゆれに注意して解説本文を検索して確かめる）。
- 教科書の本文扱いであること（「発展」「参考」「コラム」「研究」でないこと）を確かめる。
- 総復習の行でも、解説に明記のない内容を範囲に書いたら † を付ける。
- 年号は、出典で出来事と結び付いて書かれているものだけを載せる。
- 語句の表記は出典に合わせる（例：「ドッジ＝ライン」と表記の違う出典しかない場合は載せない）。
- 教科書会社によって用語が異なる場合は、確認できた範囲で併記する（例：獲得免疫／適応免疫）。

### 5.6 範囲の判断

1. 学習指導要領の内容・内容の取扱いにあるか → あれば範囲内。
2. 解説に記述・例示があるか → あれば範囲内（† なし）。
3. 教科書会社の検定済み教科書で**本文**扱いか → 1社でも本文扱いなら範囲内として † 付きで載せてよい。どの社も「発展」扱いなら載せない。
4. 教科書会社が「学習指導要領では扱いのない項目」と明言している、または解説が扱う内容を限定している → 載せない（例：生物基礎の腎臓による体液濃度の調節）。
5. 学習指導要領が「〜を中心に」とする場合は禁止ではない。本文で扱う教科書があれば † 付きで載せてよい（例：数学Ⅲの部分積分を2回使う場合、数学Ⅱの3次関数と接線で囲まれた面積）。
6. 学習指導要領が「必要に応じて扱う」とする事項は範囲内（例：英語コミュニケーションⅠの分詞構文）。
7. 学習指導要領が指導の方法を制限している場合は、その練習そのものの行を立てない（例：英語の和訳・和文英訳の練習。「単に英語を日本語に置き換える指導としない」）。

### 5.7 入試の列

**印の定義**

| 印 | 意味 |
|---|---|
| ○ | 入試の出題範囲に含まれる内容 |
| △ | 出題範囲の内容だが、活動そのもの（実演・発表・討論・レポート作成など）は筆記の学力検査で直接は問われにくい |
| — | 出題範囲外（共通テストで出題されない科目・内容、別枠の単元など） |
| 空欄 | 未指定（個別試験：大学が決まっていない） |

**△ の基準（全教科共通）**：その行の中心が「活動そのもの」か「筆記でも問える内容・技能」かで決める。

| 教科 | △ にする行 | ○ にする行 |
|---|---|---|
| 中学国語 | 話合い・スピーチ・朗読の実演、伝え合う交流、創作・制作、書写の実技 | 意見文・批評文・手紙・報告を書く、読んで考えたことを文章にまとめる（出題方針エ） |
| 中学英語 | 音読、即興のやり取り、説明・スピーチの実演、その振り返りと復習 | 会話を続けるための表現の学習、スピーチの構成を考える、音声の知識、聞く・読む・書く |
| 中学数学 | 課題学習（問題の発見・計画、レポートと発表） | その他（作図・証明・データの活用を含む） |
| 中学理科 | 発表・討論・意思決定そのものが中心の行 | 観察・実験、データの分析・解釈、実験を計画して行う探究（出題方針イ・ウ・エ） |
| 中学社会 | 地域調査の主題設定・野外調査・発表、模擬裁判、探究の発表 | 資料の読み取り・考察 |
| 高校数学Ⅰ・Ⅱ | 課題学習 | その他 |
| 高校情報Ⅰ | 制作・発表・討議が中心の行 | 実習（プログラミング・シミュレーション・データ分析） |
| 高校国語（現国・言文） | 論述・発表・話合いの活動そのもの | 読み比べ、話合いの記録を題材にした読解の知識 |
| 高校英語（英Ⅰ・Ⅱ・論Ⅰ） | 話すこと・書くことの活動 | 聞いたり読んだりして情報を整理する、段落の構成を理解する、文法・語彙 |
| 高校地歴公民 | 発表・振り返り | テーマの設定、資料と仮説（問題作成方針が仮説・資料に基づく問題を明示） |

- 数学Ⅲ、論理国語、文学国語、古典探究、英語コミュニケーションⅢ、論理・表現Ⅱ・Ⅲは科目全体が共通テストの範囲外なので全行「—」。
- 基礎科目の行は専門科目（『化学』など）の出題範囲としては扱わない。学習の前提であることは注と前提単元で示す。
- 別枠の単元は「—」。
- 個別試験の列は空欄（大学の指定後に調べて埋める）。
- 各資料の `EXAM_NOTE` に、出典の原文に基づく印の説明を書く。

### 5.8 単元のねらいと前提単元

- **ねらい（aim）**：学習指導要領の当該内容の柱書・事項と解説の趣旨に基づき、その単元で身に付ける知識・技能と思考力等を1〜2文で書く。宣伝的な表現や教科書固有の題材名は使わない。復習の単元は範囲を書く。
- **前提単元（prereq）**：その単元の学習に**直接**必要な前の単元（1〜3件程度）。
  - 根拠：解説の系統の記述（「中学校第3学年の〜を踏まえ」「『物理基礎』の〜を基礎として」「『公共』で身に付けた〜」など）、学習指導要領の履修の順序の規定、同じ内容の学年・科目の配列。
  - 学年・科目・資料をまたいでよい（例：数学Ⅰの単元 → `jhs_math:3-x`、物理の単元 → 物理基礎の単元・数学Ⅱの三角関数、地理探究 → 中学公民の地方自治）。
  - 資料群に前提がない単元（中学1年の最初の単元など）は空。
  - **復習・課題学習だけの単元は空**にし、扱う範囲は aim に書く。
  - 根拠がある場合は3件を超えてよい（例：数学Ⅲの「関数と極限」は数学Bの「数列」を含め4件）。

### 5.9 教科別の固有ルール

**中学英語**
- 文法事項の学年配当は東京書籍『NEW HORIZON』令和7年度用を基準とする（利用者の決定）。他社（三省堂・開隆堂・光村図書など）との違いは各学年の注に記載。
- 境界：1年＝There is …、look＋形容詞、感嘆文、過去進行形、前置詞、人称代名詞の目的格、want to（名詞的用法の導入）。2年＝未来表現、助動詞、接続詞 when・if・because・that、不定詞の3用法、動名詞、SVOO、SVOC（C＝名詞）、主語＋be動詞＋形容詞＋that、比較、受け身、It is …＋to（for なし）。3年＝現在完了形・現在完了進行形、SVOC（C＝形容詞）、SVOO（that 節・what 節）、It is …（for＋人）＋to、want＋人＋to、let・help＋目的語＋原形不定詞、間接疑問、分詞の後置修飾、接触節、関係代名詞（主格・目的格）、仮定法。
- 復習のコマ数は、140時間と教科書会社の各学年の合計の差（予備時間）の範囲。東京書籍の合計は1年99・2年98・3年88時間。

**中学国語**
- 根拠コードの書き方（4.4）を3学年で統一。
- 「近代以降の代表的な作家の作品」（第3の3(4)「いずれかの学年で」）は、各学年の読むことの事項と組み合わせた別の学習として3学年すべてに置いてよい。
- 文法は各学年とも「説明的な文章」の単元に置く（2年は用言の活用2コマ→助詞・助動詞→文法の演習）。
- 条件作文（字数・段落などの条件）は1年→2年→3年で段階的に置く（† 付き）。

**中学理科**
- 学校図書は比較表と範囲の確認から外す（3.4）。
- 各分野の授業時数はおよそ同程度（学習指導要領 第3の1(2)）。
- 3年の「エネルギーの変換と保存」は学習指導要領の内容の構成に合わせ第1分野(7)の単元に置く。

**中学数学**
- 課題学習は各学年に置き、千葉県の列は △。

**中学社会**
- 日本の諸地域の考察の仕方：学習指導要領の規定（地域ごとに①〜⑤から一つ、①〜④は少なくとも一度）を満たす組合せ（九州①・中国四国④・近畿⑤・中部③・関東②・東北②・北海道①）。
- 公民の単元の並びは教科書会社4社と同じ A→C→B→D。

**高校数学**
- 数学A・B・C の別枠（5.1）。
- 課題学習は数学Ⅰ・Ⅱで △、数学Ⅲは「—」（科目全体が範囲外）。

**高校国語**
- 共通テスト『国語』は現代の国語・言語文化のみ。
- 文学史の行は最小限（解説は「必要に応じて」）。個別試験の大学が決まってから増やすか判断する。

**高校英語**
- 分詞構文と it が名詞用法の句・節を指す文：英語コミュニケーションⅠで学習、Ⅱで活用、Ⅲで演習・復習の中で扱う（根拠コードは `(1)エ`）。
- 英語コミュニケーションⅡの文法は「Ⅰで学んだ〜の活用」として書く（解説 p.65）。

**高校理科**
- 専門科目の注に「基礎を付した科目の内容は学習の前提」と、問題作成方針の「基礎を付した科目の内容との関連も考慮する」を書く。

**高校公民**
- 倫理では、思想家と中心概念の組合せは出典の文脈どおりにする（例：夏目漱石は近代的自我、幸徳秋水は社会主義。パスカルは東京書籍のシラバス案どおり倫理の導入の行）。
- 法令に関わる記述は条文を優先する（例：労働基準法第13条は、基準に達しない部分を無効とし、その部分に法の基準を適用する）。

## 6. 検証のロジック

### 6.1 生成時の自動検証（`tools/build_md.py`）

| 番号 | 検証 | 失敗時の直し方 |
|---|---|---|
| 1 | 区分ごとの行数の合計＝標準時数（別枠を除く） | 同じ単元の中で統合・追加してそろえる |
| 2 | `COS_ITEMS` の全項目がどこかの行の根拠に含まれる | 根拠コードを付け忘れた行に追加するか、その事項を扱う行を作る |
| 3 | 根拠コードがすべて `COS_ITEMS` に存在する（誤記なし） | 本文の記号に合わせて直す |
| 4 | 〔用語・記号〕（`TERMS`）がすべて行の名称・要点に現れる | 該当する行の要点に書く |
| 5 | 単元の行数が教科書会社の配当時数の範囲内 | 単元間でコマを移す、または対応付けを見直す |
| 6 | 行の解説ページに、根拠コードの小見出しがある（前後1ページ許容） | ページを本文で確かめて直す。見出しが自動で取れない場合は `KAISETSU_EXTRA` に手入力 |
| 7 | 全行に rid があり重複しない | `tools/assign_ids.py` を実行 |

### 6.2 横断点検（`tools/lint.py` → `reports/lint.md`）

- ERROR：rid の未設定・重複・書式違い、前提単元の参照先がない、区分・入試の印が定義外、要点の出典IDが `SOURCES` にない。
- WARN：要点本文（出典の印と「主な語句」を除く）が 25 字未満・220 字超、同じ資料の中の同名の行（範囲を名前に含む行を除く）、根拠が空の行（復習を除く）。
- INFO：ねらい・前提単元の記入数。

### 6.3 語句の照合（`tools/checks/run_all.py`）

補った語句（† B・C）が、示した出典のテキスト（`sources/text/`）に実在するかを資料ごとのスクリプトで照合する。登録されている照合：公共・倫理、歴史総合、地理、世界史探究、日本史探究、中学公民、中学歴史（追加分と † の点検）、中学地理・歴史（見直しでの追加分）、情報Ⅰ、政治・経済、化学、地学、物理、生物、中学理科。すべて「NG 0」を合格とする（中学歴史の「世阿弥」はルビ抽出による既知の1件）。

照合の注意：PDF の抽出テキストは語の途中にふりがなや改行が挟まることがある（空白・改行を除いて照合し、ルビを挟んだ一致は目視で確かめる）。短い語の部分一致に注意（例：「レンツ」が「ローレンツ」に、「フロン」が「火山フロント」に一致）。

### 6.4 人による照合

- 変更・作成した行の2割以上（少なくとも10行）を無作為に選び、解説本文（`sources/text/` の該当ページ）と読み合わせる。
- 語句を補った行は、出典の前後の文脈を目視で確かめ、行の内容と合うことを確認する（文脈が合わなければ合う行へ移すか載せない）。

## 7. 作業手順

### 7.1 新規作成（実績）

1. **パイロット**：中学数学を作り、形式・粒度を利用者と確定。
2. **資料の取得**：`tools/fetch_pdf.py` で学習指導要領・解説・入試資料・編修趣意書を取得（`sources/raw/`・`sources/text/`）。印刷ページと PDF ページのずれは、各ページ冒頭付近の「数字だけの行」の最頻値の差で求める。
3. **解説の見出しとページ**：`tools/kaisetsu_headings.py`（国語は `headings_kokugo.py`、情報は `headings_info1.py`）で見出し→ページの対応表を作り、取れない箇所は本文を読んで `KAISETSU_EXTRA` に入れる。
4. **配当時数**：`tools/hensyu_tables.py`・`hensyu_hours.py` で編修趣意書の表を抽出し、読み取れた値だけを `publishers` に記録。
5. **データの作成**：`COS_ITEMS` を本文から正確に転記 → 単元と行を作成 → `build_md.py` の検証を全合格にする → 2割以上を解説と照合。
6. **展開**：共通テスト科目 → 中学残り4教科と個別試験用科目を並行。作業要領は `docs/WORKER_BRIEF.md`・`docs/WORKER_BRIEF_JHS.md`。
7. **語句の補充**：歴史・倫理・中学社会で教科書会社の公開資料を探し、確認できた語句だけを † と出典付きで補う。資料ごとに照合スクリプトを作る。

### 7.2 全体見直し（2026-09-29 の実績）

1. 作りの改善：固定ID（`assign_ids.py --all`）、単元の aim・prereq 欄、JSON 版（`export_json.py`）、横断点検（`lint.py`）、照合の集約（`tools/checks/`）、`tools/` の整理、README。
2. 教科ごとの点検（`docs/REVIEW_BRIEF.md`）：視点1（受験の専門家）と視点2（教材生成）で点検・修正し、aim・prereq を記入。同じ教科の学年・関連科目は同じ担当にまとめた（19担当）。
3. 取りまとめ：担当の報告を読み、判断を統一（判例集）、語句の不足（理科・地理・政経・情報など）を追加で補充、資料間の整合（△の基準、課題学習、英語の文法の扱い、前提単元の規則）を確認。
4. 仕上げ：`rebuild_all.py`（生成・目次・JSON・lint）と `tools/checks/run_all.py`。

結果：1,916行を修正、† の行 744→1,037、要点25字未満 102→0 行、220字超 17→4 行、全417単元にねらい、365単元に前提単元。

### 7.3 データを直す標準手順

1. 大きな変更の前に `data/` を `backup/data_<日付>_<内容>/` に控える。
2. `data/<モジュール>.py` を編集する（直接、または変更指示ファイルを `tools/apply_changes.py` で反映）。出力の Markdown・JSON は編集しない。
3. 新しい行があれば `python tools/assign_ids.py data.<モジュール>`。
4. `python tools/build_md.py data.<モジュール> "output/<出力名>.md"` で検証。
5. 全体を `python tools/rebuild_all.py`（生成・目次・JSON・lint）。lint の ERROR 0 を確認。
6. 語句を補った資料は `python tools/checks/run_all.py` で NG 0。
7. 変更した行の2割以上を解説と照合。
8. `reports/review/<モジュール>.md` に記録を追記。

### 7.4 環境上の注意

- Windows・PowerShell。Python 実行前に `[Console]::OutputEncoding=[Text.Encoding]::UTF8; $env:PYTHONIOENCODING="utf-8"`。
- Google ドライブ上のため、編集直後に古い内容が読まれることがある。数秒待って再実行する。フォルダーの削除が同期で失敗することもある。
- PowerShell の `python -c` で中かっこ・引用符を含むコードは失敗しやすい。スクリプトファイルに書いて実行する。
- 複数の作業を並行するときは、資料単位で担当を分け、他の担当のファイルを編集しない。`rebuild_all.py`・`export_json.py` は全資料を書き出すので、最後に1回だけ実行する。
- PDF の抽出で文字化けする場合（高校理科の解説など）は pdfplumber・pypdfium2・pdfminer で抽出し直す。

### 8.2 特定の学校・大学に合わせる

- 東京書籍以外の英語教科書を使う学校では、文法事項の学年配当を注の他社比較に基づいて読み替える。

## 9. 既知の限界

- 1コマの区切りと単元内のコマ配分は一例で、特定の学校の計画ではない。
- 公開資料で確認できなかった語句は載せていない（各資料の「この資料の限界と注意」に列挙）。主な例：
  - 中学歴史：中大兄皇子、中臣鎌足、北条時宗、徳川家光、日ソ共同宣言、645年・1853年など
  - 高校日本史：平将門、真珠湾、所得倍増
  - 高校歴史総合：ポツダム宣言、1868年、1889年など
  - 政治・経済：ケインズ・修正資本主義、固定相場制・ブレトン＝ウッズ協定
  - 化学：メチルオレンジ、標準状態の条件の数値
  - 物理：仕事関数・質量欠損の語（量の説明は要点にある）
  - 地理：古期造山帯・新期造山帯、メルカトル図法
  - 情報Ⅰ：残差
  - 中学理科：水素・アンモニアの発生に使う物質、記録タイマーの打点間隔
- 最新版に時数の記載がない科目は古い検定版の配当時数を使った（3.4）。
- 個別試験の列は空欄。
- 現行の学習指導要領に基づく。
