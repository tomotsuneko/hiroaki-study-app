# 中学校の学習内容マップ 作業要領（担当者向け）

高校向けの `tools/WORKER_BRIEF.md` を先に読み、その規則（正確さ最優先、推測で書かない、変更禁止のファイル、ツールの使い方、内容の書き方、完了条件）にすべて従うこと。この文書は中学校で異なる点だけを書く。

## 手本

- `data/jhs_math.py` と `output/中学校_数学.md`（中学数学・完成済み）。区分（Segment）の立て方、学年ごとの根拠コード、課題学習・復習の扱い、高校入試列の書き方をそのまま手本にする。

- 解説（`sources/links_jhs.txt` に全教科の URL がある）:

  - 外国語編 https://www.mext.go.jp/content/20210531-mxt_kyoiku01-100002608_010.pdf

## 合意済みの方針（中学校）

1. 区分は学年（社会は分野）。コマ数は標準授業時数に一致させる。教科書会社の計画の予備時間は「復習（予備時間）」単元にし、範囲を明示した復習コマにする（手本と同じ）。
2. 入試列は `EXAM_COLUMNS = ["高校入試（千葉県）"]`、`EXAM_DEFAULT = {"高校入試（千葉県）": "○"}`。学力検査で直接は問われにくい行（話合いの実演など）は、千葉県の出題方針の原文を踏まえて `"△"` にしてよく、使う場合は意味を `EXAM_NOTE` に明記する。
3. 国語・英語は、学習指導要領の事項で小項目を立て、教科書の教材名には依存しない（利用者の決定）。英語の学年配当は学習指導要領が学年を分けていないため、教科書会社の年間指導計画（最低3社）に基づき、根拠を注に書く。
4. † の行は残す。教科書会社の配当時数は最新版（令和7年度用）を使う。

担当教科・学年（分野）、データモジュール名、出力ファイル名、区分の設定。
