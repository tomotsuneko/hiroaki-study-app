## 2. 集合と命題（数Ⅰ-021〜030）

| 項目 | 決め事 |
|---|---|
| 要素 | \(a\in A\)、\(a\notin A\)。「要素」は数Ⅰ-021 で定義する（数Ⅰ-009 のまとめで ⊂ を先に紹介済み） |
| 集合の表し方 | 書き並べる：\(A=\{1,\ 2,\ 3\}\)。条件で表す：\(A=\{\,x\mid x>2\,\}\)（KaTeX は `\{\,x\mid x>2\,\}`） |
| 部分集合 | \(A\subset B\)（解説の記号）。\(A=B\) の場合を含むかどうかは、出典で確かめてから書く |
| 空集合 | 語は「空集合」（東京書籍のシラバス案・数研出版のシラバスにある）。記号は \(\emptyset\)（`\emptyset`）で、「このページでの記号」と注記する（学習指導要領解説 p.93・94 と地図はギリシャ文字のファイ φ。2026-10-02 に字形を確認）。「空集合はどの集合の部分集合でもある」は数Ⅰ-021・022 に明記がないので、使うページ（数Ａ-003 など）で部分集合の定義から一言説明する |
| 共通部分・和集合 | \(A\cap B\)、\(A\cup B\) |
| 全体集合・補集合 | 全体集合 \(U\)、補集合 \(\overline{A}\)（`\overline{A}`） |
| 要素の個数 | \(n(A)\) と \(n(A\cup B)=n(A)+n(B)-n(A\cap B)\) は数学Ａ「場合の数と確率」で扱う（解説）。021〜030 では扱わない |
| 図 | 全体集合は長方形、集合は円。塗りは色だけに頼らず斜線も使う。「ベン図」の語は数研出版のシラバスにある（使うなら出典に書く） |
| 命題・条件 | 条件は \(p\)、\(q\)、条件を満たすものの集合は \(P\)、\(Q\)。「\(p\) ならば \(q\)」を \(p\Longrightarrow q\)、同値を \(p\Longleftrightarrow q\) と書く（記号の扱いは出典で確かめる）。条件の否定は \(\overline{p}\) |
| 集合が等しい | \(A=B\) は「要素がすべて一致すること」、\(A\subset B\) と \(B\subset A\) が両方成り立つことと同じ（数Ⅰ-021） |
| 文字の範囲 | とくに断らない限り \(x\) は実数、\(n\) は整数（数Ⅰ-021・024） |
| 補集合を条件で書く | \(\{\,x\mid x<-1\ \text{または}\ 3\leqq x\,\}\)（コンマで区切らない） |
| ベン図の部分と塗り | 4つの部分は ①A だけ、②\(A\cap B\)、③B だけ、④どちらにも入らない（数Ⅰ-023）。\(\overline{A}\) は右上がりの斜線、\(\overline{B}\) は右下がりの斜線と薄い色。SVG の中では上線が崩れるので「B の補集合」と言葉で書く |
| 反例 | 「\(P\) の要素で \(Q\) の要素でないもの（\(P\cap\overline{Q}\) の要素）」（数Ⅰ-024） |
| 判定の言い方 | 「十分条件であるが、必要条件ではない」「必要条件であるが、十分条件ではない」「必要条件でも十分条件でもない」「必要条件でもあり、十分条件でもある」（数Ⅰ-025）。「必要十分条件」の名前は数Ⅰ-026 |
| 記号の断り | ⟹・⟺ は教科書の扱いを公的資料で確かめられなかったので、各ページで最初に使う箇所に「このページでは」と断って使う（数Ⅰ-024〜029） |
| 必要十分条件 | 数Ⅰ-025 の「必要条件でもあり、十分条件でもある」を数Ⅰ-026 で「必要十分条件」と名付ける（026 に両者をつなぐ文がある） |
| 部分集合と一致 | \(P\subset Q\) は \(P=Q\) の場合も含む（数Ⅰ-021 の定義） |
| 否定の言いかえ | 「偶数でない」を「奇数」と言いかえるのは、全体集合が整数のときに限ると明記する |
| 「または」 | 数学の「または」は両方を満たす場合も含む（和集合の定義から述べる） |
| 証明の書き方 | 結びは「（証明終わり）」。対偶を使う証明は「対偶『…』を証明する」で始め、「対偶が真であるから、もとの命題も真である」で結ぶ。「既約分数」「互いに素」（数Ａ-074）は使わず「それ以上約分できない分数」と書く |
| 証明の例 | 解説の例（「\(n\) を整数とするとき、\(n^2\) が偶数ならば \(n\) も偶数」「直線外の1点からその直線に引ける垂線は1本だけ」「√2 が無理数」）を扱う。偶数・奇数を文字で表すのは中2-008 |

## 3. 二次関数（数Ⅰ-031〜056）

| 項目 | 決め事 |
|---|---|

| 平方完成の手順 | 数Ⅰ-034 の手順①〜④はページの中だけの番号 |
| 最大・最小 | 「\(x=1\) で最小値 \(-3\) をとる」。最大値がないときは「最大値はない」 |
| 判別式 | \(D=b^2-4ac\)。\(D/4\) は扱っていない（数Ⅰ-047・053）。2つの判別式は \(D_1\)、\(D_2\)（数Ⅰ-055） |
| 演習の型の名前 | 「型A〜D」はページごとの呼び方で、ページによって中身が違う（数Ⅰ-042・051・055・056）。単元末演習で別の分け方をするときは「別の分け方」と断る |
| 図の説明文の数式 | figcaption の中の KaTeX の根号は、共通 CSS の修正（2026-10-01）で表示されるようになった。数Ⅰ-054 は普通の文字の √ で書いている |

| 二次不等式の解 | \(x<\alpha,\ \beta<x\)、\(\alpha<x<\beta\)（\(\alpha<\beta\)）。\(x<\alpha,\ \beta<x\) は「または」の意味（数Ⅰ-026 を参照）。「すべての実数」「解はない」。1点だけ除く解は \(x\neq\alpha\) でなく「\(x=\alpha\) 以外のすべての実数」 |

| 公式カードの条件 | 「すべての実数で \(ax^2+bx+c>0\) ⇔ \(a>0\) かつ \(D<0\)」には「\(a\neq0\) のとき」を付け、\(x^2\) の係数に文字があれば係数 0 の場合を別に考えると書く（数Ⅰ-053・055・056） |
| ほかのページの型を指す | 「数Ⅰ-055 の型B」のようにページ番号を付ける |
| 操作部品の無理数 | 小数第3位を四捨五入して「≈」を付ける。本文で根号を含む座標の近似値を添えるときは「およそ −0.41」 |
| 最大・最小の印 | 数Ⅰ-041・042 は図に ■、数Ⅰ-040 は文字「最大」「最小」（どちらも可。新しいページは文字のラベルを基本にする） |

## 3b. 図形と計量（数Ⅰ-057〜078）

| 項目 | 決め事 |
|---|---|
| 三角比の記号 | \(\sin A\)、\(\cos A\)、\(\tan A\)（KaTeX は `\sin A`）。一般の角は \(\theta\)。角度は「°」を付ける（\(30^\circ\)） |
| 三角形の辺 | △ABC で \(a=\mathrm{BC}\)、\(b=\mathrm{CA}\)、\(c=\mathrm{AB}\)、外接円の半径 \(R\)、内接円の半径 \(r\)、面積 \(S\) |
| 鈍角への拡張 | 解説の言い方（原点を中心とする円周上の点 P の座標が \( (\alpha\cos\theta,\ \alpha\sin\theta) \)）に沿い、半径は \(\alpha\)（「このページでは」と断る）。半円は \(y\geqq0\) の部分、点 A\( (\alpha,\ 0) \)、角 \(\angle\mathrm{AOP}=\theta\)、垂線の足 H。「単位円」は数Ⅰ-063 で定義（啓林館のシラバス案・数Ⅱ-062 で確認）。\(\tan90^\circ\) は「定めない」（表では「なし」）。「象限」は使わない（解説 p.39 に「第1象限」の語はあるが、このページ群では使わない決め事）。範囲は \(0^\circ\leqq\theta\leqq180^\circ\) |
| 特別な角の値の形 | \(\dfrac{1}{\sqrt2}\)・\(\dfrac{1}{\sqrt3}\) を主にする（地図の数Ⅰ-066 の要点が \(-\dfrac{1}{\sqrt2}\)）。\(\dfrac{\sqrt2}{2}\)・\(\dfrac{\sqrt3}{3}\) は「同じ値」と併記してよい。入力問題は両方を受け付ける。数Ⅰ-058 はクロスチェックで「\(\dfrac{1}{\sqrt2}\)（\(=\dfrac{\sqrt2}{2}\)）」の併記にした。計算で出る値（辺の長さなど）は分母を有理化した形を主にする |
| 頂点・角の書体 | 数式中の頂点は立体：\(\angle\mathrm{A}\)、\(\triangle\mathrm{ABC}\)（`\angle\mathrm{A}`）。辺の長さの文字 \(a,\ b,\ c\) は斜体 |
| 角の個数の言い方 | 三角比の値から角の個数を書くときは、公式カードでも範囲と境目（\(0^\circ\)・\(90^\circ\)・\(180^\circ\)、\(|k|>1\) で解なし）を省かない（数Ⅰ-066 のクロスチェックで S1） |
| 近似値の言い方 | 表や機器の値を「打ち切った近似値」と書かない（四捨五入した値） |
| 相互関係の番号 | 関係1：\(\tan A=\dfrac{\sin A}{\cos A}\)、関係2：\(\sin^2A+\cos^2A=1\)、関係3：\(1+\tan^2A=\dfrac{1}{\cos^2A}\)（数Ⅰ-061・065） |
| 角の答えの書き方 | 角が2つあるときは「\(\theta=30^\circ,\ 150^\circ\)」、入力は「30°,150°」。三角比の値から角を求めるときは \(0^\circ\leqq\theta\leqq180^\circ\) のすべての解を答える |
