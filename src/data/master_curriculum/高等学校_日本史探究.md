# 学習内容マップ 高等学校 地理歴史（日本史探究）

- 作成日：2026-09-29
- 準拠：高等学校学習指導要領（平成30年告示）第2章第2節 地理歴史 第4 日本史探究。令和4年4月1日施行、同日以降に第1学年に入学した生徒から適用 [S1]
- 標準単位数：3単位（1単位時間50分、35単位時間を1単位として計算＝105コマ）[S1]
- 共通テスト：令和9年度の出題科目『歴史総合，日本史探究』に対応。歴史総合の内容は別資料（高等学校_歴史総合.md）で扱い、本資料には含めない [S3]。問題作成方針は、用語などを含めた個別の事実等に関する知識だけでなく、事象の意味や意義、特色や相互の関連等を考察する力を求め、教科書等で扱われていない資料の情報と授業で学んだ知識を関連付ける問題なども検討するとしている [S19]
- 構成：大項目A〜Dはこの順に扱う（内容の取扱い(2)ア）。各大項目は (1) 時代の転換を理解して「時代を通観する問い」を表現 → (2) 資料から時代の特色の「仮説」を表現 → (3) 主題を設定して事象の意味や意義を考察し、解釈や画期を表現、の順で、Dには (4) 現代の日本の課題の探究 がある [S1][S2]
- † の行の要点末尾の「主な語句：…。［語句：S9］」は、解説に明示のない教科書レベルの主な語句（人名・事件・制度・文化財など）を、教科書会社の公開資料（S9〜S18）で確認できたものに限って補ったもの。表記は資料の記載どおり（教科書紙面の抜粋ではルビを除いた表記）
- 区分「探究」：資料や既習事項を基に問い・仮説を表現したり、主題を設定して歴史の解釈や画期を根拠を示して表現したりするコマ。区分「活用」は、資料を手がかりに情報を読み取り考察するコマ
- 構成：大項目＝教科・科目（地理歴史（日本史探究））／中項目＝単元／小項目＝授業1コマ（50分）
- 合計：105コマ（日探 105）＝標準授業時数（高校は標準単位数×35）
