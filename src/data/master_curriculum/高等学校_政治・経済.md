# 学習内容マップ 高等学校 公民（政治・経済）

- 作成日：2026-09-29
- 準拠：高等学校学習指導要領（平成30年告示、令和4年度から年次進行で実施）第2章第3節 公民 第3「政治・経済」。標準単位数2単位＝70コマ [S1][S2]
- 共通テスト：令和9年度大学入学共通テストの出題科目『公共，政治・経済』のうち「政治・経済」の部分。「公共」は別資料（高等学校_公民（公共・倫理）.md）で扱い、本資料には載せていない [S3]
- 「政治・経済」は、全ての生徒が履修する「公共」を履修した後に履修する選択科目（学習指導要領 第3款 1(2)）[S1]
- 区分「探究」＝学習指導要領 A(2)・B(2) の「諸課題の探究」のコマ。探究する課題は生徒や学校、地域の実態などに応じて選択させ、適切かつ十分な授業時数を配当することとされている（内容の取扱い(2)イ(ア)）[S1]
- 次期学習指導要領は高等学校で令和14年度入学生から順次実施（令和16年度から全面実施）の予定とされている（今後変更の可能性あり）[S9]
- 構成：大項目＝教科・科目（公民（政治・経済））／中項目＝単元／小項目＝授業1コマ（50分）
- 合計：70コマ（政経 70）＝標準授業時数（高校は標準単位数×35）
